# 動手改任何東西之前，先讀 `AGENTS.md`

本專案的完整規則寫在**專案根目錄的 [`AGENTS.md`](../../AGENTS.md)**。
那是唯一的規則來源，這個檔案只是指過去的路標。

**請現在就去讀它，讀完再開始工作。**

---

## 為什麼規則不寫在這裡

本專案由 **Antigravity IDE、Claude Code、OpenAI Codex 三個工具並行維護**。
每個工具自動載入的檔案都不一樣：

| 工具 | 自動載入 |
|------|---------|
| Antigravity | 這個 `.agent/rules/`，以及 `~/.gemini/GEMINI.md`（全域） |
| Claude Code | `CLAUDE.md`（它用 `@AGENTS.md` import 進完整規則） |
| OpenAI Codex | `AGENTS.md` |

如果每個工具各放一份規則，它們會開始漂移——**那正是這個專案已經發生過的事故**
（見 `AGENTS.md` §0：曾有兩份文件對同一件事給出相反說法）。
所以規則只有一份，各工具用自己的方式指向它。

**不要把 `AGENTS.md` 的內容複製到這裡。** 要改規則就去改 `AGENTS.md`。

---

## 最低限度：如果你只讀得到這一頁

以下三條違反後會**靜默**出錯（畫面正常、成品是錯的），但完整脈絡在 `AGENTS.md`：

1. **絕對不要對版號做全域字串取代。** 升版只改 `package.json` 與 `package-lock.json`。
   文件裡的 `## [v4.31.2]`、「v4.27 起才開始壞」是**歷史事實**，不是待更新欄位。
2. **改程式碼前先讀 `docs/技術架構說明.md` §0「鐵律」。**
3. **Git 提交訊息一律使用繁體中文。**
