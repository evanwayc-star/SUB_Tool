### 新增與改善
- **極簡純黑高對比風（OLED High-Contrast）UI/UX 全面升級**：
  - 介面採用純黑底色（`--bg: #000000;`）與分層極深黑面板（`#0a0a0a` / `#121212` / `#1c1c1c`），搭配俐落 1px 線框（`#222222` / `#333333`）。
  - 操作按鈕與工具列組件加入即時高亮反饋（`:hover` 時 `border-color: var(--accent); color: #ffffff;`），去除模糊重陰影，使各編輯區塊邊界清晰俐落。
  - 右鍵選單與彈出對話框採用純黑深底與 1px 線框，操作反應俐落專業。
- **字幕列表斑馬紋表格排版（Zebra Striping）**：
  - 字幕列表採用交替深灰與純黑的斑馬紋行背景（奇數行 `#000000` / 偶數行 `#0c0c0c` / Hover `#181818`），大幅強化長文字與多行字幕橫向閱讀時的舒適度與視線連貫性。
  - 目前播放行（Active）與選取行（Selected）維持標準 5px 指示色條與高對比半透明背景，狀態切換同一影格即時響應且文字不位移。
- **時間軸字幕塊簡約平整化**：
  - 時間軸字幕塊 `.cue-block` 採用純淨湛藍色塊與 1px 亮藍邊框，選取狀態採用鮮明琥珀金（`#f59e0b`）與純黑粗體字，剪輯點與字幕區間一目了然。
- **字幕搜尋 / 取代浮動視窗作用軌道提示**：
  - 搜尋視窗標題列整合作用中字幕軌道徽章（例如 `[主對白]` 或 `[軌道 1]`），滑鼠懸停顯示詳細提示。
  - 切換字幕列表軌道或開啟搜尋視窗時，即時聯動同步更新作用軌道名稱。
