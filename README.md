# SUB Tool — 多軌時間軸上字幕工具

Arctime 風格的上字幕編輯器，同一份 `dist/index.html` 同時支援**網頁版**與 **Electron 桌面版**。

目前版本以 `package.json` 為準；歷次變更見 [`docs/版本變更紀錄.md`](docs/版本變更紀錄.md)。

## 功能摘要

- **多軌字幕時間軸**：拖曳區塊調整起訖、換軌、磁吸對齊；`I`/`O` 上字幕
- **字幕樣式系統**：字級／座標／角度／對齊／字色／框線／陰影／底色／字距行距／**直書**／
  自備字型，可**逐句覆蓋**，可存成**常用樣式**跨專案套用。預覽＝mpv＝匯出燒錄**三路一致**
- **在播放器上直接拖字幕**定位與旋轉；安全框（100%／90%／80%＋中心線）與可切換的**時間碼監看浮水印**
- **影片序列 / 多視訊軌**：切割、修剪、疊層、子母畫面、透明度、淡入淡出與**軌間溶接**；可解除影音連結，讓影片與原音各自剪輯
- **圖片素材疊加**：PNG/JPG 成為獨立視訊素材，可在播放器直接拖移、四角等比縮放，並保留位置、大小與片段時間；匯出時以靜態畫面完整覆蓋該片段長度
- **WebCodecs 自寫預覽引擎**：多軌**即時合成**預覽（與匯出一致），串流式 demux 不限片長
- **專案音訊路由**：可設 2／4／6／8／10／16／18 或自訂總聲道；每個素材獨立對應來源聲道到輸出 bus，支援 Mono、Stereo、5.1 與純多聲道 WAV
- **匯出影片 / WAV**：影像與音訊一律從**母素材**解碼，絕不使用 Proxy 或播放快取；ProRes 422 HQ（24-bit PCM 母帶）或 MP4（H.264 + 依聲道數配置 AAC）、GPU 編碼、字幕燒入
- **交付時間碼**：播放器的 `TC` 僅供監看；影片匯出可另選「壓入時間碼浮水印」，由輸出範圍的原始時間碼開始計算
- **字幕檢查**：找出常見簡體字、日文假名／韓文／俄文、零寬空白等非允許字元；繁簡共用字與台灣常用字不誤報
- JKL 穿梭輪（最高 5×）、`←/→` 逐格定位、可自訂快捷鍵（支援匯出／匯入）
- 匯入 / 匯出：SRT、ASS/SSA、Adobe Encore 時碼、純文字、XLSX
- FPS 自動偵測（23.976 / 24 / 25 / 29.97 DF/NDF / 30）
- 多音軌混音器（以**專案輸出軌**為主；獨奏 / 靜音 / 逐聲道電平表）
- 桌面版：MXF / MKV / AVI 等非原生格式、mpv 秒開、媒體快取

## 版本比較

| 版本 | 啟動方式 | 媒體能力 |
|------|----------|----------|
| 網頁版 | `啟動工具.bat` 或開啟 `dist/index.html` | MP4 / MOV(H.264) / MP3 / WAV |
| **桌面版（推薦）** | `啟動桌面版.bat` 或雙擊 `.subtool` 專案檔 | 上述 + MXF / MKV / AVI / 多音軌 / 雙擊開啟專案 |

## 快速開始

需要 [Node.js](https://nodejs.org) 18+。ffmpeg / ffprobe 與 mpv 已內建於 `electron/`，
找不到時才回退系統安裝版本。

```bash
npm install          # 第一次
npm run electron     # 桌面版：build + 啟動 Electron（或雙擊 啟動桌面版.bat）
npm run build        # 網頁版：打包成 dist/index.html（或雙擊 啟動工具.bat）
```

開發模式、發版流程與完整指令見 [`docs/開發與驗證.md`](docs/開發與驗證.md)。

## 給接手的工程師

- **發版流程**與 CDP 驗證方法詳見 [`docs/開發與驗證.md`](docs/開發與驗證.md)。
- **升版時絕對不要對版號做全域字串取代。** 文件裡的 `## [v4.31.2]`、
  「v4.27 起的安裝版才開始壞」是**歷史事實**，不是待更新的欄位。
  這件事已經出過兩次事故，把 95 筆版本歷史一次毀掉（見 `AGENTS.md` §0.1）。
- **單元測試涵蓋純邏輯與專案資料完整性**（時碼、格式、工具、音訊路由、圖片幾何、
  輸出範圍與字幕文字檢查）。UI 與媒體行為一律用桌面版 Electron 視窗驗證——
  方法與兩個「驗證方法本身出錯」的真實案例都寫在開發與驗證文件裡。
- **變更紀錄請寫「為什麼」和「怎麼驗的」**，不要只寫「修了 X」。這份習慣讓好幾個坑
  （字型家族名、filtergraph 跳脫、CSS 蓋掉 `[hidden]`）沒有被重踩。
