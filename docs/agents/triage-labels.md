# Triage 標籤

那些 skill 用**五個角色**在描述 issue 的狀態。這份檔案把角色對應到本 repo
issue tracker 裡**實際存在**的標籤字串。

| skill 裡的角色 | 本 repo 的標籤 | 意義 |
|---------------|---------------|------|
| `needs-triage` | `needs-triage` | 維護者需要評估這張 issue |
| `needs-info` | `needs-info` | 等回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，AI 可無人值守直接接手 |
| `ready-for-human` | `ready-for-human` | 需要人來實作 |
| `wontfix` | `wontfix` | 不會處理 |

當 skill 提到某個角色（例如「apply the AFK-ready triage label」），
就用這張表右欄對應的標籤字串。

本 repo 使用**預設名稱**，左右欄相同。`wontfix` 沿用 GitHub 建 repo 時就有的
既有標籤（說明為 "This will not be worked on"），沒有另建重複的。

> 若日後改用別的標籤詞彙，**只改右欄**，不要改左欄——左欄是 skill 的固定用語。
