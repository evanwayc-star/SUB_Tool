# Triage 標籤

工程 skill 的角色與 GitHub 現行標籤同名。依票況使用既有標籤：

| 角色／標籤 | 使用時機 |
|---|---|
| `needs-triage` | 等待維護者評估 |
| `needs-info` | 需要補充資訊 |
| `ready-for-agent` | 規格完整，Agent 可自主實作 |
| `ready-for-human` | 需要人工實作 |
| `wontfix` | 已決定不處理 |

GitHub 若改名，在本表記錄角色對應的新標籤，保留 skill 角色名稱。讀票、換標籤與關票見 [Issue 工作流程](issue-tracker.md)。
