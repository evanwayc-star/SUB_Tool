# 工程任務的領域文件

本專案共用一套詞彙和決策。探索前讀根目錄 [CONTEXT.md](../../CONTEXT.md)，再查任務涉及的 [ADR](../adr/)。Issue、提案、測試與除錯假說沿用相同名稱。

| 遇到的情況 | 處理 |
|---|---|
| 新詞或別名 | 先查既有定義。確有新概念時，用 `/domain-modeling` 補進 `CONTEXT.md`。 |
| 作成架構決策 | 在 `docs/adr/NNNN-決策標題.md` 記錄理由、代價與推翻條件。未決事項留在提案。 |
| 提案牴觸已採用的 ADR | 指明 ADR 編號、衝突與重開決策的證據。 |
| 新增文件類別 | 更新 [AGENTS 文件職責](../../AGENTS.md#3-文件職責)與 [README 導覽](../../README.md#文件導覽)。 |

全專案共用根層檔案，無須建立 `CONTEXT-MAP.md` 或分模組的 ADR 目錄。
