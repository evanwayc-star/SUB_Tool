# ADR-0001 每份交付各自一個 ffmpeg 程序

2026-07-25 已接受並實作。

## 決策

每份交付有獨立的 ffmpeg 執行流程、進度、預估時間與後續封裝／光碟製作。佇列預設同時執行 1 份，可調至 3 份。執行中可追加工作或逐份停止，失敗限於該份。「暫停後續工作」只暫停排程，已開始的工作繼續執行。「繼續後續工作」恢復排程。

## 理由與代價

當時希望逐份暫停、繼續與停止，並可追加工作、隔離失敗及查看逐份進度。匯入實測證明 ffmpeg 可單次讀取並多路輸出，適合減少約 44 GB MXF、186 GB ProRes 的重複讀取。但啟動時輸入、濾鏡與目的地已固定，各路共用程序與進度，無法獨立操作。

N 份工作會重讀、重做合成與字幕燒錄，但第一份可先完成。預設單工控制解碼、記憶體及硬體編碼壓力。過去重開同一來源曾建立過多 hwaccel 實例而耗盡 VRAM，大型 MXF 同時跑多路 NVENC 也可能拖慢匯出與預覽。

## 重評條件

若實測顯示整批耗時主要來自重複合成，評估先產生共用無損／ProRes 母帶，再逐份轉碼。重評時一併驗證逐份控制、動態追加、失敗隔離及進度。[匯出架構](../技術架構說明.md#匯出) · [原生程序與佇列](../Electron_維護手冊.md)
