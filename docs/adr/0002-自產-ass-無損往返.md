# ADR-0002：自產 ASS 以中繼資料保證無損往返

## 狀態

已接受。決策日期：2026-07-28。

## 背景

標準 ASS 的 Style／Dialogue 無法完整、可逆地表達 SUB Tool 的直書、逐句覆蓋、行距與精確影格。僅解析標準內容，無法保證本工具匯出的 ASS 再匯入後保留原有時間及外觀。

## 決策

自產 ASS 同時包含一般播放器可讀的標準內容，以及不參與顯示的版本化中繼資料。本工具只在中繼資料通過驗證後，用它還原字幕與軌道；外部 ASS 或無效中繼資料回退到標準欄位的最佳努力解析。

新產生的標準內容另有時間格式標記。只有缺少該標記與有效中繼資料的舊版自產檔，才依匯入時確認的 FPS 修正舊有半格百分秒偏移。

## 後果

自產檔可以保留標準 ASS 不能完整表達的資料，一般播放器仍讀取標準字幕內容。代價是本工具必須持續維護中繼資料版本、形狀與範圍驗證，以及安全回退。

外部 ASS 不承諾完整重建所有 libass 功能。標準解析保留可識別的 Style、位置及文字前靜態覆寫；字內局部樣式與動畫仍超出既有還原範圍。不能把這個限制擴張成自產檔可以遺失資料，也不能將任何帶相似註解的外部檔直接視為可信自產資料。

目前匯入計畫、樣式及時間的責任分工見[技術架構說明](../技術架構說明.md#字幕樣式)與[FPS 不變量 I3](../FPS_時碼一致性.md#i3-影格格網只有-snaptimetoframe)。
