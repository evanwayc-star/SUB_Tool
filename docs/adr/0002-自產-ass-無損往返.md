# ADR-0002 自產 ASS 以中繼資料無損往返

2026-07-28 已接受。

## 決策

匯出同時寫入播放器可讀的 Style／Dialogue，以及不參與顯示的版本化中繼資料。標準欄位無法可逆地表達直書、逐句覆蓋、行距與精確影格。

| 匯入條件 | 行為 |
|---|---|
| 自產檔且中繼資料版本、形狀及範圍有效 | 從中繼資料還原字幕、軌道、時間與外觀。相似註解本身不能證明來源可信。 |
| 由其他工具產生，或中繼資料無效 | 依標準欄位讀取可識別的 Style、位置、文字前靜態覆寫。字內局部樣式及動畫超出還原範圍。 |
| 辨認為舊版自產檔，且同時缺少新時間格式標記與有效中繼資料 | 依匯入時確認的 FPS 修正歷史半格百分秒偏移。 |

## 代價與重評條件

維護者須保留中繼資料版本驗證、外部 ASS 的標準解析及舊檔相容路徑。替代格式若要取代此設計，須能讓標準播放器顯示，並讓自產檔在上述欄位與影格上無損往返。[字幕樣式](../技術架構說明.md#字幕樣式) · [FPS 不變量 I3](../FPS_時碼一致性.md#i3-影格格網只有-snaptimetoframe)
