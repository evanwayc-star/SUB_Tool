# ADR-0002：自產 ASS 以中繼資料保證無損往返

## 狀態

已接受（2026-07-28）

## 背景

SUB Tool 的直書、逐句覆寫與行距等資料無法完全由標準 ASS 的 Style／Dialogue 結構可逆地重建；
使用者需要把本工具匯出的 ASS 再匯入時，保留原本的時間軸影格與視覺樣式。

## 決策

SUB Tool 匯出的 ASS 保持可供一般播放器讀取的標準內容，並附帶不會顯示的版本化中繼資料。
本工具匯入有效中繼資料時以它還原字幕與軌道；沒有有效中繼資料的外部 ASS 則以標準欄位做最佳努力解析。
新版標準內容另帶時間格式標記；偵測到沒有標記的舊版自產檔時，才依目前確認的 FPS 修正其舊半格百分秒偏移。

## 後果

自產 ASS 的往返可維持完整資料，外部播放器會忽略中繼資料；外部 ASS 不承諾無損還原所有
libass 功能。外部 fallback 只轉換 Style、位置與文字前的靜態覆寫，忽略字內局部樣式與動畫。
中繼資料必須版本化、驗證後才使用，並在失效時安全回退到標準 ASS 解析。
