# ADR-0003 倒帶以實際呈現畫格節流

2026-08-27 已接受。正向預覽來源於 2026-11-11 調整，後續規格見下表。

## 決策

同時最多一個呈現請求。等候時只保留最新目標。只有目前可見 presenter 回報與請求相符的畫格，才能更新時間軸呈現位置。固定計時器累積 seek 會讓解碼器追趕過期畫格，畫面落後於時間軸。

| Presenter | 可接受的呈現證據 |
|---|---|
| HTML video | 實際畫格 callback。 |
| mpv 播放定位 | 命中目標的 `time-pos` 與同一請求的 `playback-restart`。 |
| mpv 暫停定位 | command ack 與命中目標的 `time-pos`。同格沒有新事件時，host 在 ack 後查位置。 |
| WebCodecs | 全部可見層已完成繪製。 |

符合條件的單一 mpv 片段可先用原生反向播放。長 GOP 可能中途停住，整段都要監看呈現位置是否持續下降。停滯時由時間軸依經過時間、精確專案 FPS、倍率計算最新目標。持續倒帶靜音，方向鍵逐格保留短促 scrub 音訊。

一般長距離 seek 共用呈現 session。等待期間接受最新 play／pause 意圖，畫格到達前，presenter 時鐘、序列推進與音訊 follower 維持停止。

## 代價與邊界

解碼跟不上時會跳過中間畫格，限制操作延遲。倒帶 session 負責節流，presentation core 管呈現請求的生命週期。控制器不另設 seek 佇列、epoch、watchdog 或固定 30 FPS 計時。新增 presenter 必須提供可與請求配對的呈現證據。遲到的解碼、pause、背景音訊接管不能覆寫新意圖。

## 預覽來源的演進

| 時點 | 來源選擇與取捨 |
|---|---|
| 2026-08-27 | 背景建立短 GOP 720p Proxy，包含可原生播放的 H.264／H.265 MP4。多數編碼器用 GOP 1，NVENC 用 GOP 2。倒帶可於相同來源時間切 Proxy，停止後正播、快轉與交付讀母素材，以快取空間換取倒帶順暢。 |
| 2026-11-11 | 大型 NAS 母片正播可能緩衝。流暢模式允許正向播放已完成的 720p Proxy，也曾支援本機副本。代價是預覽細節、複製等待與空間。停止倒帶回到選定的正向來源。 |
| 2026-11-13（v9.1.2） | Proxy 改為 480p、1000 kb/s，直接讀取母素材旁快取，移除 NAS 到本機的複製入口。[版本變更紀錄](../版本變更紀錄.md) |
