# 人聲波形模型研究

初次研究：2026-10-05。文件、固定來源與程式重新查核：2026-10-21。

目的為在本機分析較少配樂干擾的人聲波形。操作見[人聲波形](../使用說明.md#人聲波形)，顯示、取消與工作所有權見[技術架構](../技術架構說明.md#人聲波形的顯示邊界)。

## 為什麼先分離，再判斷語音

對原音直接做 VAD 遮罩，只會移除無人說話區域；說話時重疊的音樂仍在。現行路徑先用 UVR MDX 分離人聲，再以 Silero VAD 判斷語音區域。分離的人聲也可能含歌聲、殘響或配樂，不能把結果視為乾淨對白保證。

## 張量與來源時間

MDX 使用 stereo 44.1 kHz、nFFT 7680、hop 1024、dimF 3072、dimT 256。Silero VAD 使用 16 kHz、512-sample 視窗及 64-sample context；介面依[官方 wrapper](https://github.com/snakers4/silero-vad/blob/master/src/silero_vad/utils_vad.py)核對。

來源音訊須先依影片原點對齊，切塊後仍保留原 sample 座標。不能只核對輸出長度；前置靜音、分塊接點與峰值位置都要驗。現行實作入口為 [vocal-waveform-source.js](../../src/vocal-waveform-source.js)、[worker](../../src/vocal-waveform-worker.js)與[分離引擎](../../src/vocal-waveform-engine.js)。

## 下載、快取與隱私邊界

首次需從固定來源下載模型，模型下載及快取命中均驗證長度與雜湊。音訊推論在本機執行，不把音訊送給模型供應者；首次下載模型仍需要網路。IndexedDB 不可用時走既有退路，不能令快取等待卡死推論。

部署時應讓 JS 與外部 WASM 版本一致；本專案採 extern-WASM 避免多份大型 WASM 內嵌至單檔 HTML。部署依據見 [ONNX Runtime Web 官方文件](https://onnxruntime.ai/docs/tutorials/web/deploy.html)。

## 已有證據與適用範圍

原研究使用 15 秒 TTS 混入 330／660 Hz 配樂，真模型推論後，說話期間兩個配樂頻率的幅度分別約剩原音 0.5%／3.9%；桌面波形中純配樂區為零，語音區仍保有峰值。

這是單一受控 fixture 的歷史紀錄，2026-10-21 只重新核對固定模型 metadata、套件版本、載入與時間座標程式及主要來源，沒有重跑分離品質評測，也不能推論所有影片都無配樂、歌聲或殘響。更換模型或依賴時，重驗實際音訊分離、來源時間、分塊接點、取消／重試、快取損壞及無 WebGPU 的退路，再更新研究日期與結果。
