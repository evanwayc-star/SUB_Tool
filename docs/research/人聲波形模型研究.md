# 人聲波形模型研究

研究日期：2026-10-05。目的為離線分析「移除說話時重疊配樂」的人聲波形；操作見 [使用說明](../使用說明.md#人聲波形)，流程與取消規則見 [技術架構](../技術架構說明.md#人聲波形的顯示邊界)。

選用真正分離來源的 UVR MDX 模型，再在分離結果上辨識說話區段。只對原音做 VAD 遮罩仍保留說話時的配樂，不符合此功能需求。

| 項目 | 固定版本／來源 | 驗證 |
|---|---|---|
| 人聲模型 | [UVR-MDX-NET-Voc_FT](https://huggingface.co/Blane187/all_public_uvr_models/blob/fddec39677560e41e3194f24a9e4c4cd32ef0e83/UVR-MDX-NET-Voc_FT.onnx)，MIT | 66,762,490 bytes；SHA-256 `534b2070fcc7df514b13ef660dc8cbb328679c2374d04354a5c42bb14ecce111` |
| 語音模型 | [Silero VAD ONNX](https://huggingface.co/onnx-community/silero-vad/blob/e71cae966052b992a7eca6b17738916ce0eca4ec/onnx/model.onnx)，MIT | 2,243,022 bytes；SHA-256 `a4a068cd6cf1ea8355b84327595838ca748ec29a25bc91fc82e6c299ccdc5808` |
| STFT | [web-audio-separation](https://github.com/incidentist/web-audio-separation) 0.3.1，MIT | 公開 `PffftSTFT` 支援固定 MDX 張量形狀及 WASM FFT；測試實際往返精度與來源對齊 |
| 推論 | [ONNX Runtime Web 部署文件](https://onnxruntime.ai/docs/tutorials/web/deploy.html)，套件 1.30.0，MIT | Worker 優先 WebGPU、失敗回 WASM；CDN 的 WASM 與套件版本一致，Vite 使用 extern-WASM 條件避免把多份大型 WASM 內嵌到 HTML |

MDX 使用 stereo 44.1 kHz、nFFT 7680、hop 1024、dimF 3072、dimT 256；語音辨識使用 16 kHz、512 samples 與 64-sample context，介面核對 [Silero 官方 wrapper](https://github.com/snakers4/silero-vad/blob/master/src/silero_vad/utils_vad.py)。模型下載與模型快取命中均核對長度及雜湊，音訊不傳給模型供應者。

本機以 15 秒 TTS 混合 330／660 Hz 配樂進行真模型推論，說話期間兩個配樂頻率的幅度分別剩下原音約 0.5%／3.9%；桌面人聲波形的純配樂區為零，語音區仍有峰值。這是受控 fixture 的結果，不能推論所有影片都完全無殘響、配樂或歌聲。模型能力與下載可用性應在依賴或模型版本更換時重新驗證。
