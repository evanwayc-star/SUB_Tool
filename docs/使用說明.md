# SUB Tool — 上字幕工具

> 對應版本：v5.2.0｜最後更新：2026-07-23

Arctime 風格的上字幕工具，**同一份 `index.html` 同時支援網頁版與桌面版**。

| 版本 | 啟動方式 | 適合 | 媒體能力 |
|------|----------|------|----------|
| **桌面版（推薦）** | 雙擊 `啟動桌面版.bat` | 完整功能 | **MXF / 多音軌同時播放 / 數 GB 長片**（系統 ffmpeg） |
| 網頁版 | 雙擊 `啟動工具.bat` | 免安裝、快速 | MP4/MOV/MP3/WAV 原生；MXF 受瀏覽器記憶體限制 |

---

## 一、桌面版（解除所有限制）

### 安裝與啟動

1. 先安裝 [Node.js](https://nodejs.org)（一次性）。
2. 先安裝 [ffmpeg](https://ffmpeg.org)（一次性，MXF/多音軌需要；放入 PATH 或 `C:\Program Files\FFMPEG\bin\`）。
3. 雙擊 **`啟動桌面版.bat`**。第一次會自動 `npm install`（下載 Electron），之後即可直接開啟。

> 桌面版啟動時會自動偵測 ffmpeg；若未安裝，原生 MP4/MOV/MP3/WAV 與字幕編輯仍可使用。

### 桌面版多了什麼

- **直接讀 MXF / MKV / AVI 等非原生格式**：自動用系統 ffmpeg 轉一支 720p 代理預覽片（畫面），原音軌另外抽取保持原質。
- **多音軌「同時」混音播放**：每條音軌抽成暫存檔，各自以串流方式播放並與影片同步 → 可同時聽到所有音軌，或單獨獨奏（S）、靜音、調整音量。**不受記憶體限制，長片也可以。**
- **整片波形**：以低取樣（8kHz 單聲道）由 ffmpeg 產生整部片的波形，記憶體友善。
- **專案 `.subtool` 記住影片完整路徑**：重新開啟專案會**自動載入原影片**，不需再手動選取。
- **存檔/匯出走原生對話框**：直接寫入你選的位置（非瀏覽器下載資料夾）。

## 二、網頁版（免安裝）

- 雙擊 **`啟動工具.bat`**：首次自動 ### 桌面版

```bash
npm install          # 第一次安裝
npm run electron     # build + 啟動 Electron
# 或雙擊 啟動桌面版.bat
```

> **提示**：桌面版打包或安裝後，作業系統會將 `.subtool` 專案檔關聯至此程式。往後只要直接雙擊 `.subtool` 專案檔，即可開啟軟體並自動載入該專案進度！。
  （本專案已改為 Vite + ES 模組，原始 `index.html` 是開發入口，**不能直接雙擊**；要邊改邊看請用 `npm run dev`，開 http://localhost:8777 熱更新。）
- 原生播放 MP4 / MOV(H.264) / MP3 / WAV（數 GB 串流不佔記憶體）。
- MXF / 多音軌 / 數 GB 大檔受**瀏覽器記憶體上限**限制，請改用桌面版。

## 三、操作（兩版相同）

### 三大區塊

**播放窗**（左上）｜**字幕列表**（右）｜**時間軸**（下）。拖曳區塊之間的**分隔線**可調整字幕列表寬度、時間軸高度。

### 播放窗

- 匯入影片時**自動偵測 FPS**；FPS 可選 **23.98 / 24 / 25 / 29.97（Drop-frame）/ 29.97（Non-Drop）/ 30**。時間以「**時:分:秒:格**」(例 `01:05:28:16`) 顯示；29.97 Drop-frame 以分號分隔格數（例 `01:05:28;16`）。
- **拖放開啟**：把影音檔直接拖進視窗即可。桌面版的拖放與「🎬 影音」按鈕走完全相同的流程（ffprobe 實測 FPS、系統 ffmpeg 背景轉檔／多音軌抽取、mpv 秒開），MXF 等非原生格式一樣支援。
- 控制鍵依序：後退 5 秒、後退 1 秒、退 1 格、播放/暫停、進 1 格、前進 1 秒、前進 5 秒。
- **JKL 穿梭輪**：`J` 倒帶、`K` 暫停、`L` 正播；連按 J/L 逐級加速（1× → 1.5× → 2× …每階 0.5×，**最高 5×**）。
- **播放速度**：在影片畫面或左側的速度數字（例如 `1x`）上按右鍵，可選常用倍率或「自訂速度…」；可輸入 **0.1×–4×**，切換時會自動結束 JKL 穿梭。
- **TC 時間碼監看**：安全框右側的 **`TC`** 是播放器監看用浮水印；開啟後會在左上顯示目前播放點的時間碼。這個開關會記住，但**不會自動燒進匯出檔**。
- **雙擊時間數字**可直接輸入時間：例 `01235512`→`01:23:55:12`、`35722`→`00:03:57:22`、`8:13`→`00:00:08:13`；超過片長會提示「超過片長」且不跳轉。**右鍵時間數字**可複製時間碼。
- 多軌道在同一時間都有字幕時會**疊加全部顯示**，各軌位置由「字幕列表 → 樣式區」的垂直位置自行調整。

### 上字幕流程

1. 選一條字幕（或用 `Shift+↑ / ↓` 在所選字幕上/下方新增空白字幕）。
2. 播放到開始處按 `I`、結束處按 `O`（設定**被選字幕**的起訖）。
3. 在列表輸入文字，或**雙擊時間軸字幕區塊**直接編輯。

也可先匯入「純文字」聽打稿，再逐句用 `I`／`O` 套時間。

> **空白專案快速開始**：無需先載入影片；啟動時已有「軌道 1」，可直接移動播放點、按 `I`/`O` 新增空白字幕，再按 `\` 縮放至已建字幕範圍。

### 字幕列表

- 上方**下拉選單**：切換顯示的軌道（或全部）。
- 下方**樣式區**：即時反映在預覽，且**與 mpv／匯出燒入完全一致**（預覽＝成品）。欄位排列如下：

  ```
  行1  大小 60/80＋數值 │ B I │ 對齊 [上下▼][左右▼] │ 直 │ 字色＋白紅黃 │ 字型▼
  行2  座標 X Y │ 角度 │ 字距 行距 │ 框線＋框色 陰影 │ 底＋底色＋不透明度
  行3  常用樣式 [套用▼] ☆存為常用 ⚙管理 │ ⇩全軌統一
  ```
  - **在播放器上自由擺放單一句**（v5.2.0）：**抓著預覽窗裡的字幕拖＝只挪那一句**（不影響其他句），滑鼠**移到字幕上**會浮出**虛線框＋頂端圓形旋轉把手**，拖把手＝旋轉該句（按住 **Shift** 吸附 15°）。這樣改出來的是**該句的逐句覆蓋**（列表標 ✱ 自訂）；**整軌的標準位置請用下面的座標 X／Y**。一次拖曳＝一個還原點（`Ctrl+Z` 可復原）；**鎖定的軌道拖不動**。
  - **座標＝像素**（v5.2.0）：**X／Y** 直接填**畫面像素**（相對影片解析度，例如 1920×1080 影片填 `960 / 980`）。內部以百分比保存，**換不同解析度的影片，字幕不會跑掉**。
  - **角度**（v5.2.0）：填幾度就轉幾度（**順時針為正**），**繞錨點**旋轉（＝「對齊」指定的那一側；左右中＋上下中時就是文字塊正中心）。
  - **對齊**（v5.2.0 改為兩個下拉）：**左右對齊**（左／中／右）與**上下對齊**（上／中／下）——多行／多句字幕彼此的對齊方式，同時決定文字塊以哪一側貼齊座標。**左右選「中」＋上下選「中」時，座標就是文字塊的正中心**。
  - **直書**：逐字直排、標點自動轉直排形式（，。「」→ ︐︒﹁﹂）；直書時「行距」＝字與字的間隔。
  - **字型（自備字型資料夾）**：把字型檔放進 **`SUB_Tool/font/`** 就會出現在字型下拉——每個字型一個子資料夾（**資料夾名＝顯示名稱**，例如 `font/更紗黑體/sarasa-mono-tc-nerd-regular.ttf`）；支援 `.ttf/.otf/.ttc/.woff2`。**預設為更紗黑體**（v5.2.0 起；原為台北黑體）。預覽、MXF 的 mpv 預覽、匯出燒錄**都用同一份字型檔**，不必安裝到系統，換電腦帶著資料夾即可（v5.2.0 起匯出會自動改用字型檔內部的真實家族名，**資料夾名可隨意命名**）。
    - **要換掉某個字型**：把該子資料夾裡的字型檔換成別的即可（資料夾名不用動，也不必改設定）——例如想把更紗黑體從 Mono 版換成 Gothic 版，直接換檔就好。
    - **一個資料夾請只放一個字重**：程式一個資料夾只取一個字型檔（v5.2.0 起會自動挑**最接近 Regular 且非斜體**的那個）。多放 Bold／Light／Black 沒有用，只會讓安裝檔變大——粗體／斜體是由「B／I」按鈕控制的。
  - **面板改的是「選取中的那一句」**（v5.2.0）：點選一句字幕後，面板標題會顯示**第 N 句樣式**，所有改動**只影響那一句**（列表標 **✱ 自訂**）。**多選**（Ctrl／Shift 點選）時標題顯示**「已選 N 句樣式」，改動會同時套用到選取的每一句**（v5.2.0；欄位顯示的是第一句的值）。**沒有選取任何字幕時**，標題顯示**「整軌樣式」**，改動才會套到整條軌道。
  - **一鍵套用整軌**：按面板的 **⇩ 全軌統一**，把**目前這句的樣式套用到整條軌道的每一句**（原本設過自己樣式的句子也會一併統一；會先告知句數，可 `Ctrl+Z` 復原）。
  - **另一種只改某一句的方式**：**雙擊時間軸上那句的區塊**（不是列表列——雙擊列表列是直接改字）→ 展開「✱ 樣式覆蓋」→ 勾選要改的欄位（未勾＝繼續跟著軌道）。時間軸區塊會顯示 **✱**。位置與角度則直接在播放器上拖（見上）。要讓某幾句用完全不同的樣式（例如旁白 vs 對白），比較省事的作法是**開一條新字幕軌**，把那些句子右鍵移過去，再設定該軌的樣式。
  - **常用樣式**：「☆ 存為常用」把目前軌道樣式存成具名樣式（**跨專案保存**），下拉即可套到任何軌；「⚙ 管理」**編輯**／改名與移動／刪除。
    - **資料夾分類與匯入匯出** (v5.2.0)：可以在管理介面中將樣式移動到資料夾中。匯出時會自動建立資料夾結構，匯入時也可以一次選取整個資料夾，批次匯入裡面的所有樣式。
    - **編輯**（v5.2.0）：按下後該樣式會**暫時套到目前這條軌**當草稿，你就用平常那個樣式面板調整、**畫面即時看得到**；面板上方會出現橘色提示列。按 **完成** 就把它存回這組常用樣式，**所有原本套用這組樣式的軌與句子一起跟著變**；按 **取消** 則原樣還原（借來當草稿的那條軌若本來沒套用這組樣式，完成後也會還原，不會被順手改掉）。
    - 清單第一筆固定是**內建的「預設字幕樣式」**（標示「內建」）：字級 80／白字／黑框 2／無陰影／粗體／下對齊＋中對齊／座標 (960, 972)＝**80% 安全框的底線**／角度 0／無底色／字距行距皆 1。它**只能套用，不能改名或刪除**，被改壞時隨時按它就回到出廠設定（v5.2.0）。
  - **逐句樣式覆蓋**：**雙擊字幕**開啟編輯視窗 → 展開「✱ 樣式覆蓋」——單句可覆蓋顏色/字級/粗斜/框線/陰影/字距/行距/字型/直書/角度（未勾選＝繼承軌道）；時間軸區塊會顯示 **✱** 標記。
  - **每條字幕右側的樣式摘要**（v5.2.0 定版）：兩行讀完該句的實際生效樣式——
    - 行1：`字 80 | 下對齊 | 中對齊 | 台北黑體 | 色 ● | 邊 ● - 2`（字級／上下對齊／左右對齊／字型／文字色／框線色-粗細）
    - 行2：`座標(960,972) | 角度 0 | 橫式 | 底 ● - 50 % | 距 1 / 1`（座標／角度／直橫書／底色-不透明度／字距-行距）
    - **顏色只給色點**（滑鼠移上去看色名）；**底** 亮＝底色塊開、暗＝關。
    - 最右欄顯示**套用中的常用樣式名稱**；若該句有覆蓋則顯示 **✱ 自訂**。
- 點選字幕：`Ctrl`+點=多選、`Shift`+點=範圍選；右鍵可把選取（含多選）**移到其他軌道**。
- 內容超出畫面時，旁邊/下方自動出現捲動條。

### 字幕檢查

- 按字幕列表右上方的 **✓ 檢查**（或數字鍵盤 `Num 9`）可開啟檢查面板；點任何編號會選取並跳到對應字幕。
- 新增的「**含非繁中／英文／數字／符號**」項目會找出：明確簡體字、日文／韓文／其他文字、零寬空白等隱藏字元，以及繁簡共用字。
- **紅色編號**代表含明確簡體或其他不允許字元；**黃色編號**代表只含繁簡共用字（例如「后、干、台、里、了、出、回」），屬於台灣繁中可能合法但需要人工確認的情況。把滑鼠移到編號上可查看被偵測到的字元。

### 影片序列（多視訊軌，各軌獨立成列）

- 載入的影片會顯示為藍色區塊，放在**自己的影音軌列**上，**區塊內直接畫出該段的音波**，列頭並含該軌的**混音（M／S／音量）**（v5.2.0 起影音合一，一列＝影片＋波形＋混音；軌列較高，可拖列頭下緣調整）。時間軸由上而下為：**時間尺 → 影音軌（各一列）→ 字幕軌**。**拖曳區塊**＝移動影片在時間軸上的位置；**拖左右邊緣**＝修剪（只播來源的一段，區塊右上顯示 ✂）；**右鍵**＝切割／交換順序／重設修剪／從序列移除。
- **多視訊軌（像字幕軌一樣，可無限增加）**：每條視訊軌都是獨立的一列，左側有自己的**軌道列頭**——**雙擊改名**、**👁 顯示／隱藏**（隱藏軌不列入預覽）、**＋ 新增軌**（在其上方插入）、**✕ 刪除軌**（連同其片段；至少保留一軌、且不刪含主影片的軌）、**🔒 鎖定軌**（鎖定後該軌片段**不可選取／移動／修剪／切割／刪除**，也**無法被其他片段移入**；區塊呈虛線＋斜紋、上下鍵會跳過該軌；狀態存專案、可復原）、拖列頭下緣可**調整軌高**。**上下拖曳片段＝換軌**；**同軌不重疊、不同軌可重疊＝疊層**。**播放預覽即時合成所有重疊軌**（v5.2.0 起原生 MP4；**v5.2.0 起 MXF 也支援**——背景轉好預覽 proxy 後自動接管，轉檔期間先顯示最上層；**v5.2.0 起不限片長**——改為只讀檔頭建索引、影像播到哪讀到哪，兩小時以上的長片同樣即時合成，記憶體不隨片長增加）：上層蓋住下層、上層淡變時**真正透出下層（溶接）**、子母畫面與透明度即時顯示，與匯出一致；**聲音則是所有重疊片段同時發聲**（多軌音訊試聽，各段各自同步、與匯出一致；v5.2.0 起原生 MP4 主影片也支援）。
- **`Ctrl+K`＝在播放點切割**（或按時間軸工具列「🎯 上字幕」左邊的 **✂ 切割影片** 按鈕）：把影片切成多段，各段可獨立移動、修剪、移除；右鍵段落可「與前／後一段交換」調整順序。同一來源切出的片段之間播放切換**無縫**（含 MXF）。所有剪輯操作皆可 `Ctrl+Z` 復原。
- **選取影片段（比照字幕）**：點一下影片區塊即選取（白框高亮）；選取後 `↑`／`↓` 切到上／下一段（播放頭跟到段首）、`Del` 刪除該段、**`Backspace` 關閉前方空白**（該段左移貼齊前一段結尾，前面無素材則移到開頭）、`Esc` 取消選取。選字幕與選影片段互斥，不會互相干擾。
- **匯出影片（桌面版）**：主畫面「⚙ 設定」右側的「🎞 匯出影片」可把排好的序列算成單一影片——格式選 **ProRes 422 HQ**（母帶）或 **MP4**（交付）；**顯示中的字幕軌會燒入畫面**（隱藏軌不燒，先關該軌的 👁 即可輸出乾淨影片）；解析度／FPS 沿用主影片與序列設定。（網頁版不支援影片匯出）
  - **壓入時間碼浮水印**：在 ProRes／MP4 匯出視窗勾選「壓入時間碼浮水印」後，左上角會燒入 TC。它會從輸出範圍的原始起點開始計數（例如從 `01:00:00:00` 的部分匯出，第一格仍顯示 `01:00:00:00`），使用更紗黑體等寬數字。播放器工具列的 `TC` 則僅供監看，兩者互不影響。
  - **多軌合成**：匯出會把**多視訊軌由下而上疊合**（上層覆蓋下層，與預覽一致）、**多音訊軌全部混音**；間隙為黑畫面／靜音。多軌剪輯在輸出檔裡真正生效。
  - **子母畫面／透明度**：視訊軌列頭的 **🎨 合成設定**可設該軌的**大小**（小於 100%＝子母畫面）、**位置**（九宮格）、**透明度**——**預覽即時顯示合成結果**（v5.2.0 起，原生 MP4；與匯出一致）。
  - **轉場（淡入／淡出／溶接）**：影片區塊**右鍵 →「🎞 淡入淡出（轉場）」**設定淡入、淡出秒數（影像與音訊同步淡變）；底層片段淡入／淡出黑底，**上層片段與下層重疊時的淡變＝軌間溶接（crossfade）**。區塊上顯示 **⌁** 標記，匯出時合成。**預覽即時顯示真正的溶接**（v5.2.0 起原生 MP4；**v5.2.0 起 MXF 亦同**——預覽 proxy 背景轉好後自動生效，轉檔期間暫以淡出入黑提示）：上層淡變時**透出下層**、與匯出結果一致。
  - **一鍵交叉溶接**：影片區塊**右鍵 →「🔀 與前一段交叉溶接」**，自動把此段移到上一層軌並與前一段尾端重疊、上層淡入，做出 A→B 交叉溶接（可調秒數）。
  - **音訊依混音器輸出**：匯出的聲音會依混音器的**靜音／獨奏／音量**決定（比照播放時聽到的）；音訊與影像一律從**母素材**解碼，播放用 Proxy／逐聲道 AAC 快取不會參與匯出。
  - **MP4 位元率**：選 MP4 時可自訂**影片位元率**（Mbps）。**預設值依解析度自動建議**（v4.32：像素×fps×0.12，例如 720p≈4、1080p≈7、1080p60≈15、4K≈30、4K60≈60），對話框會顯示「建議 N（依 寬×高）」。舊版一律固定 5Mbps，**4K 用 5Mbps 會嚴重壓縮、畫面像被壓過**——若嫌不夠清晰，把此值調高即可（ProRes 母帶格式則永遠固定高品質、無此問題）。MP4 的混音後音訊需重新編 AAC：**Mono 192k／Stereo 320k／5.1 640k**；完成通知會顯示檔案**實測** bitrate，該數字是交付 AAC 而非母素材的原始 bitrate。
  - **要最高畫質就選 ProRes**：ProRes 422 HQ 是**固定品質、不受位元率限制**的剪輯母帶格式（10-bit 4:2:2 + 24-bit PCM 音訊），輸出直接讀**原始母帶**、不經 proxy。若需要無損音訊，選 ProRes 或純 WAV。
  - **顯示卡加速**：MP4（H.264）編碼會使用顯卡（NVENC／QuickSync／AMF）；**ProRes 一律 CPU 編碼**（ffmpeg 無 GPU ProRes 編碼器）。來源解碼兩者皆嘗試硬體加速。
  - **怎麼確認有沒有在用 GPU**：①**狀態列右下角**顯示 `引擎：系統 ffmpeg ✓ · GPU NVENC`（綠色＝有 GPU 編碼器，滑鼠移上去有詳細說明）；②**匯出中**的進度標籤會寫「匯出 MP4（GPU NVENC）… 45%」；③**匯出完成**後顯示 ffmpeg **實際使用**的編碼器與耗時，例如「已匯出影片（GPU h264_nvenc，耗時 12.3s）」。
- 再匯入影片（按鈕或拖放）時會詢問「**加入序列**（接在最後一段之後）或**取代**」——可把多支影片排在同一條時間軸連續上字幕或粗剪比對。
- **同一視訊軌內**的區塊不可重疊（不同軌之間可重疊＝疊層）；區塊間的空隙播放時顯示**黑畫面**、時碼照走。字幕時碼永遠以**時間軸**為準，不隨影片移動。
- 跨段播放會自動切換影片：原生格式（MP4/MOV）幾乎無感；**mpv/MXF 換段時會有短暫停頓**（載檔）。
- 修剪／移動可 `Ctrl+Z` 復原；專案檔會記住序列（桌面版重開自動重建；網頁版需手動重加影片）。
- 注意：加入與序列 **FPS 不同**的影片會提示警告——時碼一律以序列（第一支影片）的 FPS 為準。

### 圖片素材（PNG / JPG 等）

- 從 **🎬 影音** 匯入圖片後，它會成為一個獨立的圖片片段，預設放在播放點、建立在最上層視訊軌，預設長度為 **10 秒**。可在時間軸拖移片段、調整兩端長度、切割或刪除；圖片片段不會限制其他影音／音訊的時間軸長度。
- 點選圖片片段後，播放器會顯示**虛線選取框與四個角落控制點**：拖曳圖片中央可移動位置，拖曳任一角落可等比調整大小。完成拖曳後可用 `Ctrl+Z` 復原；若該視訊軌已鎖定，圖片不可調整。
- 圖片與一般影片可重疊疊加。圖片的位置、大小、時間與所在視訊軌會保存進 `.subtool` 專案；先放圖片、後匯入影片也會保留圖片。
- 匯出影片時，圖片會在其整段時間內持續顯示，並使用與播放器相同的位置及縮放；圖片不是只在輸出開頭出現的一格。

### 影音軌的混音（M／S／音量）

- **v5.2.0 起影音合一**：不再有獨立的音訊波形列——**混音控制（M 靜音／S 獨奏／音量）就在每條影音軌的列頭**（下方一行），波形畫在影片區塊內。
- 這組狀態與**匯出**輸出、以及右上角的浮動**混音器**面板一致；多聲道 MXF 的**逐聲道**控制請用浮動混音器（🎛）。
- 上下層（疊層／子母畫面／溶接）依**軌列的上下順序**（上面＝上層）。

### 專案音訊與解除影音連結（v5.2.0 起）

- 時間軸現在固定分為：**視訊軌（上）→ 音訊素材軌（中）→ 字幕軌（下）**。匯入新的影音或音檔時，音訊素材可自行超出影片結尾，純音訊專案也能正常播放與匯出。
- **每個音訊素材只有一個片段**：在片段上按右鍵可選擇顯示 `MIX` 或其中一條來源聲道的波形；這只改變觀看的波形，不會改變實際輸出。
- **解除影音**：選取影片片段後按時間軸工具列的「🔗✂ 解除影音」，或右鍵選「解除影音連結」。完成後會新增一個原音音訊素材，影片原音自動關閉；兩者之後可各自拖移、修剪、`Ctrl+K` 切割或 `Del` 刪除。首次處理 MXF／MOV 可能需要等待 ffmpeg 建立音訊快取。
- **聲音開關**：音訊列左側與每個音訊片段的喇叭可直接切換；`🔊` 為開啟、`🔇` 為靜音。這不會刪除素材，也會影響預覽與匯出。
- **專案輸出聲道**：從「配線／音訊通道設定」選擇總聲道數與 Mono、Stereo、5.1 分組，再為每個來源指定要送到哪幾條專案 bus。混音器顯示的是**專案輸出軌**，不是單一檔案的聲道。
- **輸出**：影片匯出會帶著配置後的音訊；選擇 WAV 時，所有專案 bus 會輸出到**同一個 WAV 檔**，但每一條都是獨立的 mono 聲道。

### 時間軸（多軌道）

- **時間尺/波形**按住拖曳＝移動播放點；點軌道**空白處**＝取消所有選取。
- **只有按住左鍵不放拖曳**才會框選多句字幕。
- 拖曳字幕區塊＝移動（上下拖可**換軌道**）；拖左右邊緣＝調整起訖。拖移時會**磁吸**到播放點與其他字幕的邊界，且同軌字幕**時間碼不會重疊**。
- **複製字幕**：按住 `Alt` 拖曳字幕區塊，會複製原字幕到滑鼠放開的位置；多選字幕時會整組複製。`Ctrl/Cmd` 拖曳的既有複製操作仍可使用；拖曳左右邊緣調整時間不會複製。
- 左欄：`＋軌道` 新增、`✕` 刪除、`👁` 顯示/隱藏、**雙擊名稱可改名**；軌道過多時側邊出現上下捲動條。
- 每軌都可放字幕，**匯出時可勾選要輸出哪些軌道**。
- **輸出範圍**：播放器的 `[ In ]`／`[ Out ]` 用來設定部分匯出範圍，`✕` 清除。三個動作都會寫進 **🕘 動作紀錄**，可用 `Ctrl+Z`／`Ctrl+Shift+Z` 復原／重做。
- **🕘 動作紀錄**：開啟清單，可逐步復原(`Ctrl+Z`)／重做(`Ctrl+Shift+Z`)，點清單任一步可跳到該狀態。
- **📌 備註**：`＋ 新增` 會記下**目前播放時間點**＋文字；每項可**打勾**表示已確認；點該項的**時間**會把播放窗與時間軸跳到該時間點。

### 安全框（構圖參考線）

- 播放器工具列的 **⊹ 安全框** 鈕：開啟後在預覽畫面疊上 **100% 邊界**、**90% 動作安全框**（白實線）、**80% 字幕/標題安全框**（黃虛線）與**中心十字線**，方便對位與構圖。**只是預覽參考，不會燒進匯出**；開關狀態下次開啟程式仍記得。

## 四、字幕格式

- **匯入**（自動偵測 UTF-8 / UTF-16 / 含 BOM）：SRT、ASS/SSA、Adobe Encore（`HH:MM:SS:FF`）、純文字。

- Adobe Encore 是「影格」時碼，請先在右上設定正確 **FPS**（桌面版會自動偵測）。
