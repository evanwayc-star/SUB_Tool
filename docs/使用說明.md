# SUB Tool — 使用說明

Arctime 風格的上字幕工具，**同一份 `index.html` 同時支援網頁版與桌面版**。

| 版本 | 啟動方式 | 適合 | 媒體能力 |
|------|----------|------|----------|
| **Windows 桌面版（推薦）** | 安裝 Release，或雙擊 `啟動桌面版.bat` | 完整功能 | **MXF / 多音軌同時播放 / 數 GB 長片**（內建 ffmpeg + mpv） |
| **Apple Silicon 測試版** | 在 M 系列 Mac 從原始碼建置 unsigned DMG | 功能驗收 | 內建 arm64 ffmpeg；第一版無 mpv，MXF 先 ingest/proxy |
| 網頁版 | 雙擊 `啟動網頁版.bat` | 免安裝、快速 | MP4/MOV/MP3/WAV 原生；MXF 受瀏覽器記憶體限制 |

---

## 一、桌面版（解除所有限制）

### 安裝與啟動

1. Windows 一般使用者安裝 [Releases](https://github.com/evanwayc-star/SUB_Tool/releases/latest) 的 Setup；
   從原始碼執行才需要 [Node.js](https://nodejs.org) 並雙擊 **`啟動桌面版.bat`**。
2. Apple Silicon 目前是自行建置的 unsigned 測試版；依
   [`開發與驗證.md`](開發與驗證.md#apple-silicon-本機測試版)執行 `npm ci` 與
   `npm run dist:mac:test`，再按該頁清單驗收。

> 桌面安裝包會帶平台原生 ffmpeg/ffprobe；啟動時也會依序檢查環境變數與常見系統路徑作 fallback。
> 若全部不可用，介面會明確提示，MXF、proxy、多音軌抽取與影片匯出暫停使用。

### 桌面版多了什麼

- **直接讀 MXF / MKV / AVI 等非原生格式**：自動用桌面版 ffmpeg 轉一支 720p 代理預覽片（畫面），原音軌另外抽取保持原質。
- **多音軌「同時」混音播放**：每條音軌抽成暫存檔，各自以串流方式播放並與影片同步 → 可同時聽到所有音軌，或單獨獨奏（S）、靜音、調整音量。**不受記憶體限制，長片也可以。**
- **整片波形**：以低取樣（8kHz 單聲道）由 ffmpeg 產生整部片的波形，記憶體友善。
- **專案 `.subtool` 記住影片完整路徑**：重新開啟專案會**自動載入原影片**，不需再手動選取。
- **開啟另一個專案前會先問要不要存檔**：目前專案有未儲存的變更時，不論是從選單開啟、或直接雙擊另一個 `.subtool`，都會先跳出「儲存後開啟／不儲存直接開啟／取消」。選「儲存後開啟」但在存檔對話框按了取消時**不會**繼續開新專案，避免以為存好了結果兩邊都沒了。
- **存檔/匯出走原生對話框**：直接寫入你選的位置（非瀏覽器下載資料夾）。

## 二、網頁版（免安裝）

- 雙擊 **`啟動網頁版.bat`**：首次自動 build 並開啟 `dist/index.html`。
  （本專案已改為 Vite + ES 模組，原始 `index.html` 是開發入口，**不能直接雙擊**；要邊改邊看請用 `npm run dev`，開 http://localhost:8777 熱更新。）
- 原生播放 MP4 / MOV(H.264) / MP3 / WAV（數 GB 串流不佔記憶體）。
- MXF / 多音軌 / 數 GB 大檔受**瀏覽器記憶體上限**限制，請改用桌面版。

## 三、操作（兩版相同）

### 三大區塊

**播放窗**（左上）｜**字幕列表**（右）｜**時間軸**（下）。拖曳區塊之間的**分隔線**可調整字幕列表寬度、時間軸高度。時間軸標題右側的 **◀／▶** 可把「音軌數」到縮放控制整組收合／展開；這個工作區版面會在下次開啟程式時沿用。

### 播放窗

- 匯入影片時**自動偵測 FPS**；FPS 可選 **23.98 / 24 / 25 / 29.97（Drop-frame）/ 29.97（Non-Drop）/ 30**。時間以「**時:分:秒:格**」(例 `01:05:28:16`) 顯示；29.97 Drop-frame 以分號分隔格數（例 `01:05:28;16`）。
- **拖放開啟**：把影音檔直接拖進視窗即可。桌面版的拖放與「🎬 影音」按鈕走完全相同的流程（ffprobe 實測 FPS、ffmpeg 背景轉檔／多音軌抽取；Windows 有 mpv 時可秒開），MXF 等非原生格式一樣支援。
- 控制鍵依序：後退 1 秒、退 1 格、播放/暫停、進 1 格、前進 1 秒。需要 ±5 秒時使用
  `Ctrl`+`Shift`+`←`／`→`，播放器不再另外佔兩顆按鈕。
- **JKL 穿梭輪**：`J` 倒帶、`K` 暫停、`L` 正播；連按 J/L 逐級加速（1× → 1.5× → 2× …每階 0.5×，**最高 5×**）。Windows 桌面版會在背景準備短 GOP 預覽 Proxy；準備完成後，以 mpv 播放**單一、未修剪且從時間軸 0 開始**的影片時，倒帶會暫時使用 Proxy 維持接近快轉的平滑度，停止後在同一畫格切回母素材。程式會全程監看實際畫格，若原生倒播後來卡住也會自動改用時間軸倒退。多片段、修剪／位移片段、WebCodecs、網頁版或 Proxy 尚未就緒時使用時間軸倒退，以守住片段邊界與字幕時碼；解碼跟不上時會略過過期的中間畫格，讓畫面維持接近播放點。持續倒帶期間一律靜音，避免聲音正播、畫面倒播；單按一次方向鍵逐格仍會保留短促 scrub 音訊。
- **播放速度**：在影片畫面或左側的速度數字（例如 `1x`）上按右鍵，可選常用倍率或「自訂速度…」；可輸入 **0.1×–4×**，切換時會自動結束 JKL 穿梭。
- **滑鼠跳轉後的播放狀態**：頂部「裁切」與「設定」之間的 **跳轉繼續／跳轉暫停** 可切換行為。當影片正在播放時，以滑鼠點選或拖曳時間尺／波形、播放進度條、字幕列表／檢查結果／時間軸字幕區塊或備註時間，「跳轉繼續」會定位後維持播放，「跳轉暫停」會先停下正播／倒播再定位。原本已暫停時只會移動播放點，不會自動起播；這個選擇會在下次開啟程式時沿用。
- **TC 時間碼監看**：安全框右側的 **`TC`** 是播放器監看用浮水印；開啟後會在左上顯示目前播放點的時間碼。這個開關會記住，但**不會自動燒進匯出檔**。
- **雙擊時間數字**可直接輸入時間：例 `01235512`→`01:23:55:12`、`35722`→`00:03:57:22`、`8:13`→`00:00:08:13`；超過片長會提示「超過片長」且不跳轉。**右鍵時間數字**可複製時間碼。
- 多軌道在同一時間都有字幕時會**疊加全部顯示**，各軌位置由「字幕列表 → 樣式區」的垂直位置自行調整。

### 上字幕流程

1. 選一條字幕（或用 `Shift+↑ / ↓` 在所選字幕上/下方新增空白字幕）。
2. 播放到開始處按 `I`、結束處按 `O`（設定**被選字幕**的起訖）。
3. 在列表輸入文字，或**雙擊時間軸字幕區塊**直接編輯。

也可先匯入「純文字」聽打稿，再逐句用 `I`／`O` 套時間。

> **空白專案快速開始**：無需先載入影片；啟動時已有「軌道 1」，可直接移動播放點、按 `I`/`O` 新增空白字幕，再按 `\` 縮放至已建字幕範圍。

> **鎖定的字幕軌真的鎖得住**（v5.8.0 修正）：軌道鎖定後，`I`／`O` 不會再改到該軌字幕的時間、也不會在該軌新增字幕，`Del` 也刪不掉——**而且一定會跳出提示告訴你是哪一軌鎖著**。
> 在此之前，上字幕模式下的 `I`／`O` 完全沒有檢查鎖定狀態，看起來鎖了其實照樣改得動。

### 字幕列表

- 上方**下拉選單**：切換顯示的軌道（或全部）。
- 每列左側的**黃色粗線**代表「目前選取」，**藍色粗線**代表「播放點目前所在的字幕」；兩者可能同時出現。普通點選時間軸上的字幕會切換右側列表到該軌、顯示黃色選取，並自動捲到該句；即使該句原本已被選取，或是在大量字幕間跨軌切換，也會重新定位，不必手動滑動尋找。`Ctrl`／`Shift` 多選仍會保留，跨軌多選中的某句只有在確定是單擊（沒有拖動）後才收斂成該句，避免破壞整組拖曳。
- **播放器只顯示手動換行**：字幕文字沒有換行時，即使長句含有空格也維持單行，不會由播放器自動折行；雙擊列表列進入編輯後，可用 `Shift`+`Enter` 明確換行。字幕列表會在每個真正的換行位置顯示淺綠色 `↵`，但這只是閱讀提示，不會混進字幕文字。這項規則在 HTML 預覽、mpv 預覽與匯出燒錄都相同。
- 下方**樣式區**：即時反映在預覽，且**與 mpv／匯出燒入完全一致**（預覽＝成品）。欄位排列如下：

  ```
  行1  大小 60/80＋數值 │ B I │ 對齊 [上下▼][左右▼] │ 直 │ 字色＋白紅黃 │ 字型▼
  行2  座標 X Y │ 角度 │ 字距 行距 │ 框線＋框色 陰影 │ 底＋底色＋不透明度
  行3  常用樣式 [套用▼] ☆存為常用 ⚙管理 │ 全軌套用 │ 全軌套用-排除座標
  ```
  - **在播放器上自由擺放單一句**：**抓著預覽窗裡的字幕拖＝只挪那一句**（不影響其他句），滑鼠**移到字幕上**會浮出**虛線框＋頂端圓形旋轉把手**，拖把手＝旋轉該句（按住 **Shift** 吸附 15°）。這樣改出來的是**該句的逐句覆蓋**（列表標 ✱ 自訂）；**整軌的標準位置請用下面的座標 X／Y**。一次拖曳＝一個還原點（`Ctrl+Z` 可復原）；**鎖定的軌道拖不動**。
  - **座標＝像素**：**X／Y** 直接填**畫面像素**（相對影片解析度，例如 1920×1080 影片填 `960 / 980`）。內部以百分比保存，**換不同解析度的影片，字幕不會跑掉**。
  - **角度**：填幾度就轉幾度（**順時針為正**），**繞錨點**旋轉（＝「對齊」指定的那一側；左右中＋上下中時就是文字塊正中心）。
  - **對齊**：**左右對齊**（左／中／右）與**上下對齊**（上／中／下）——多行／多句字幕彼此的對齊方式，同時決定文字塊以哪一側貼齊座標。**左右選「中」＋上下選「中」時，座標就是文字塊的正中心**。
  - **直書**：逐字直排、標點自動轉直排形式（，。「」→ ︐︒﹁﹂）；直書時「行距」＝字與字的間隔。
  - **數值欄位滾輪微調**：滑鼠停在數值輸入框上滾一格，會依該欄位自己的步進調整；例如「行距」每格是 **0.1**。按住 `Shift` 滾動則為十倍步進。
  - **字型（自備字型資料夾）**：把字型檔放進 **`SUB_Tool/font/`** 就會出現在字型下拉——每個字型一個子資料夾（**資料夾名＝顯示名稱**，例如 `font/更紗黑體/sarasa-mono-tc-nerd-regular.ttf`）；支援 `.ttf/.otf/.ttc/.woff2`。**預設為更紗黑體**。預覽、MXF 的 mpv 預覽、匯出燒錄**都用同一份字型檔**，不必安裝到系統，換電腦帶著資料夾即可（匯出會自動改用字型檔內部的真實家族名，**資料夾名可隨意命名**）。
    - **要換掉某個字型**：把該子資料夾裡的字型檔換成別的即可（資料夾名不用動，也不必改設定）——例如想把更紗黑體從 Mono 版換成 Gothic 版，直接換檔就好。
    - **一個資料夾請只放一個字重**：程式一個資料夾只取一個字型檔（會自動挑**最接近 Regular 且非斜體**的那個）。多放 Bold／Light／Black 沒有用，只會讓安裝檔變大——粗體／斜體是由「B／I」按鈕控制的。
  - **面板改的是「選取中的字幕」**：點選一句字幕後，面板標題會顯示**第 N 句樣式**，所有改動**只影響那一句**（列表標 **✱ 自訂**）。**多選**（Ctrl／Shift 點選）時，改動會同時套用到選取的每一句。**沒有選取任何字幕時，所有樣式控制都會鎖定**並提示先選字幕，不會再默默修改整條軌道。
  - **一鍵套用整軌**：先選一則作為樣式來源，再按 **全軌套用**，會把該句的完整樣式（包含座標與角度）套到整軌；按 **全軌套用-排除座標**，則只套用外觀並保留每句原有的座標與角度。兩個按鈕使用不同圖示協助辨識，操作前會告知句數，且可 `Ctrl+Z` 復原。
  - **另一種只改某一句的方式**：**雙擊時間軸上那句的區塊**（不是列表列——雙擊列表列是直接改字）→ 展開「✱ 樣式覆蓋」→ 勾選要改的欄位（未勾＝繼續跟著軌道）。時間軸區塊會顯示 **✱**。位置與角度則直接在播放器上拖（見上）。要讓某幾句用完全不同的樣式（例如旁白 vs 對白），比較省事的作法是**開一條新字幕軌**，把那些句子右鍵移過去，再設定該軌的樣式。
  - **常用樣式**：「☆ 存為常用」把目前軌道樣式存成具名樣式（**跨專案保存**），下拉即可套到任何軌；「⚙ 管理」**編輯**／改名與移動／刪除。
    - **資料夾分類與匯入匯出** ：可以在管理介面中將樣式移動到資料夾中。匯出時會自動建立資料夾結構，匯入時也可以一次選取整個資料夾，批次匯入裡面的所有樣式。
    - **編輯**：按下後該樣式會**暫時套到目前這條軌**當草稿，你就用平常那個樣式面板調整、**畫面即時看得到**；面板上方會出現橘色提示列。按 **完成** 就把它存回這組常用樣式，**所有原本套用這組樣式的軌與句子一起跟著變**；按 **取消** 則原樣還原（借來當草稿的那條軌若本來沒套用這組樣式，完成後也會還原，不會被順手改掉）。
    - 清單第一筆固定是**內建的「預設字幕樣式」**（標示「內建」）：字級 80／白字／黑框 2／無陰影／粗體／下對齊＋中對齊／座標 (960, 972)＝**80% 安全框的底線**／角度 0／無底色／字距行距皆 1。它**只能套用，不能改名或刪除**，被改壞時隨時按它就回到出廠設定。
  - **逐句樣式覆蓋**：**雙擊字幕**開啟編輯視窗 → 展開「✱ 樣式覆蓋」——單句可覆蓋顏色/字級/粗斜/框線/陰影/字距/行距/字型/直書/角度（未勾選＝繼承軌道）；時間軸區塊會顯示 **✱** 標記。
  - **每條字幕右側的樣式摘要**：兩行讀完該句的實際生效樣式——
    - 行1：`字 80 | 下對齊 | 中對齊 | 更紗黑體 | 色 ● | 邊 ● - 2`（字級／上下對齊／左右對齊／字型／文字色／框線色-粗細）
    - 行2：`座標(960,972) | 角度 0 | 橫式 | 底 ● - 50 % | 距 1 / 1`（座標／角度／直橫書／底色-不透明度／字距-行距）
    - **顏色只給色點**（滑鼠移上去看色名）；**底** 亮＝底色塊開、暗＝關。
    - 最右欄顯示**套用中的常用樣式名稱**；若該句有覆蓋則顯示 **✱ 自訂**。
      「有覆蓋」指的是**與所在軌道不同**的設定。把某一句的樣式改回和軌道一樣
      （或直接對它套用軌道正在用的那組常用樣式）時，那些覆蓋不再有任何作用，
      會自動清掉、`✱` 也跟著消失——只有真的與軌道不同的覆蓋才會留著並標記。
- 點選字幕：`Ctrl`+點=多選、`Shift`+點=範圍選；右鍵可把選取（含多選）**移到其他軌道**。
- 內容超出畫面時，旁邊/下方自動出現捲動條。

### 字幕檢查

- 按字幕列表右上方的 **✓ 檢查**（或數字鍵盤 `Num 9`）可開啟檢查面板；點任何編號會選取並跳到對應字幕。
- 「**連續相同**」會列出前後文字相同的字幕編號；一般情況維持**橘色**。若其中一對的前句 Out 與後句 In 落在同一影格，代表兩句頭尾無縫黏接，這一對的**兩個編號都改為深綠色**；有時間間隙時兩個都維持橘色。
- **沒有查到問題的項目顯示 `N/A`。** 「超過 — 字」與「包含文字」在**尚未設定條件**時顯示 `—`，
  那是「還沒設定要查什麼」，和「查過了、沒有」是兩回事。
- 「**含非繁中等字元**」項目會找出：明確簡體字、日文／韓文／其他文字、零寬空白等隱藏字元，以及繁簡共用字。
  這一項以**淺粉色**顯示——它屬於提示性質、不是錯誤，與其他紅色警示項目區隔。
- 「**頭尾為空白**」右邊的 **Trim** 按鈕會一次刪掉該軌所有字幕的頭尾空白。
- **紅色編號**代表含明確簡體或其他不允許字元；**黃色編號**代表只含繁簡共用字（例如「后、干、台、里、了、出、回」），屬於台灣繁中可能合法但需要人工確認的情況。把滑鼠移到編號上可查看被偵測到的字元。

### 影片序列（多視訊軌，各軌獨立成列）

- 載入的影片會顯示為藍色區塊，放在**自己的影音軌列**上，**區塊內直接畫出該段的音波**，列頭並含該軌的**混音（M／S／音量）**（影音合一，一列＝影片＋波形＋混音；軌列較高，可拖列頭下緣調整）。時間軸由上而下為：**時間尺 → 影音軌（各一列）→ 字幕軌**。**拖曳區塊**＝移動影片在時間軸上的位置；**拖左右邊緣**＝修剪（只播來源的一段，區塊右上顯示 ✂）；**右鍵**＝切割／交換順序／重設修剪／從序列移除。
- **多視訊軌（像字幕軌一樣，可無限增加）**：每條視訊軌都是獨立的一列，左側有自己的**軌道列頭**——**雙擊改名**、**👁 顯示／隱藏**（隱藏軌不列入預覽）、**＋ 新增軌**（在其上方插入）、**✕ 刪除軌**（連同其片段；至少保留一軌、且不刪含主影片的軌）、**🔒 鎖定軌**（鎖定後該軌片段**不可選取／移動／修剪／切割／刪除**，也**無法被其他片段移入**；區塊呈虛線＋斜紋、上下鍵會跳過該軌；狀態存專案、可復原）、拖列頭下緣可**調整軌高**。軌道標題旁的 **🎬** 可收合／展開全部視訊軌，狀態會隨 `.subtool` 專案保存。**上下拖曳片段＝換軌**；**同軌不重疊、不同軌可重疊＝疊層**。**播放預覽即時合成所有重疊軌**（原生 MP4；** MXF 也支援**——背景轉好預覽 proxy 後自動接管，轉檔期間先顯示最上層；**不限片長**——改為只讀檔頭建索引、影像播到哪讀到哪，兩小時以上的長片同樣即時合成，記憶體不隨片長增加）：上層蓋住下層、上層淡變時**真正透出下層（溶接）**、子母畫面與透明度即時顯示，與匯出一致；**聲音則是所有重疊片段同時發聲**（多軌音訊試聽，各段各自同步、與匯出一致；原生 MP4 主影片也支援）。
- **`Ctrl+K`＝在播放點切割**（或按時間軸工具列「🎯 上字幕」左邊的 **✂ 切割影片** 按鈕）：把影片切成多段，各段可獨立移動、修剪、移除；右鍵段落可「與前／後一段交換」調整順序。同一來源切出的片段之間播放切換**無縫**（含 MXF）。所有剪輯操作皆可 `Ctrl+Z` 復原。
- **影片段也能設定大小與位置**（v5.8.0）：**右鍵 →「📐 影片大小與位置…」**，與圖片同一組欄位與同一條公式；預覽與匯出一致。這是**逐片段**的設定，和視訊軌列頭的「🎨 合成設定」（整條軌）互相疊加：先由軌的設定框出影格，片段再在影格內縮放定位，超出影格的部分會被裁掉。
- **修改持續時間**（v5.8.0）：圖片或影片片段**右鍵 →「⏳ 修改持續時間…」**，直接輸入時碼。起點不動，只改這一段播多久。上限會自動夾住並告訴你原因——影片不能超過素材本身的長度，圖片可自由延長，但兩者都不能覆蓋到**同一視訊軌**的下一段（不同軌重疊是正常的疊層，不受限制）。
- **影片／圖片右鍵選單**依「來源與定位 → 剪輯與屬性 → 聲音 → 軌道排列 → 轉場 → 移除」分組；桌面版可用「📂 在檔案管理器中顯示」定位母素材。視訊軌鎖定後，會隱藏所有修改操作，但仍保留檔案定位與「播放頭移到此片段開頭」。
- **選取影片段（比照字幕）**：點一下影片區塊即選取（白框高亮）；選取後 `↑`／`↓` 切到上／下一段（播放頭跟到段首）、`Del` 刪除該段、**`Backspace` 關閉前方空白**（該段左移貼齊前一段結尾，前面無素材則移到開頭）、`Esc` 取消選取。選字幕與選影片段互斥，不會互相干擾。
- **匯出影片（桌面版）**：主畫面「⚙ 設定」右側的「🎞 匯出影片」可把排好的序列算成單一影片——格式選 **ProRes 422 HQ**（母帶）或 **MP4**（交付）；**顯示中的字幕軌會燒入畫面**（隱藏軌不燒，先關該軌的 👁 即可輸出乾淨影片）；解析度／FPS 沿用主影片與序列設定。（網頁版不支援影片匯出）
  - **背景轉檔與監控佇列**：送出匯出後，會自動彈出「匯出佇列監控」視窗（也可隨時從主畫面右上角的「監控序列」按鈕開啟）。按鈕左側的**綠色完整圓環**表示目前沒有工作正在轉檔；出現**橘色旋轉圓環**表示至少一份工作正在執行或停止中。所有匯出任務都在背景排隊處理，不影響您繼續編輯專案。
  - **主視窗關掉後再打開**：監控視窗還在時，關閉主視窗只會把它隱藏，專案與編輯狀態仍留在記憶體。按監控視窗右上角的「🖥 開啟主視窗」即可原樣返回；若接著也關閉監控視窗，程式才會真正結束。
  - **轉檔中關閉主視窗不會中斷轉檔**：若還有工作正在轉檔時關閉主視窗，程式**不會結束**，而是把匯出佇列監控視窗叫出來、主視窗收起來，轉檔繼續跑。要真的結束程式，等轉檔完成、或在監控視窗停止工作後再關閉。
  - **轉檔中關閉最後一個視窗會先問你**：當監控視窗是唯一剩下的視窗、而且還有工作在轉檔時，關閉它會跳出確認（「繼續轉檔」／「中斷並關閉」，預設與 `Esc` 都是繼續）。選擇中斷會結束程式並清掉已寫出的半成品。主視窗還開著時關監控視窗只是收起監控畫面，轉檔照跑，不會多問。
  - **重開程式仍保留未完成工作**：等待中與上次關閉時正在執行的工作會保存在使用者資料目錄。重開後它們都回到「等待中」，而且佇列預設暫停，不會自行開始；確認設定與來源無誤後，按「▶ 繼續佇列」。若來源素材已被移動或刪除，工作會標示「來源遺失」並列出缺少的路徑。
  - **完成紀錄跨重啟保留**：已完成的工作會留在「完成紀錄」區，**關閉程式後重開仍看得到**，方便回頭核對交付了哪些檔案、什麼時候完成、花了多久（保留最近 200 筆）。這些紀錄只是紀錄，不會被重新執行。
  - **拖曳排序**：在佇列監控視窗中，可直接按住狀態為「等待中」的工作項目進行上下拖曳，藉此自由調整接下來的輸出先後順序。
  - **清除完成**：點擊視窗右上角的「🧹 清除完成」按鈕，可一鍵清空清單中所有已完成的工作紀錄，保持版面乾淨。清除是**永久的**——連同保存在磁碟上的完成紀錄一起清掉，重開程式不會回來。也可以只清單一筆（該筆的「清除紀錄」）。
  - **壓入時間碼浮水印**：在 ProRes／MP4 匯出視窗勾選「壓入時間碼浮水印」後，左上角會燒入 TC。它會從輸出範圍的原始起點開始計數（例如從 `01:00:00:00` 的部分匯出，第一格仍顯示 `01:00:00:00`），使用更紗黑體等寬數字。播放器工具列的 `TC` 則僅供監看，兩者互不影響。
  - **多軌合成**：匯出會把**多視訊軌由下而上疊合**（上層覆蓋下層，與預覽一致）、**多音訊軌全部混音**；間隙為黑畫面／靜音。多軌剪輯在輸出檔裡真正生效。
  - **子母畫面／透明度**：視訊軌列頭的 **🎨 合成設定**可設該軌的**大小**（小於 100%＝子母畫面）、**位置**（九宮格）、**透明度**——**預覽即時顯示合成結果**（原生 MP4；與匯出一致）。
  - **轉場（淡入／淡出／溶接）**：影片區塊**右鍵 →「🎞 淡入淡出（轉場）」**設定淡入、淡出秒數（影像與音訊同步淡變）；底層片段淡入／淡出黑底，**上層片段與下層重疊時的淡變＝軌間溶接（crossfade）**。區塊上顯示 **⌁** 標記，匯出時合成。**預覽即時顯示真正的溶接**（原生 MP4；** MXF 亦同**——預覽 proxy 背景轉好後自動生效，轉檔期間暫以淡出入黑提示）：上層淡變時**透出下層**、與匯出結果一致。
  - **一鍵交叉溶接**：影片區塊**右鍵 →「🔀 與前一段交叉溶接」**，自動把此段移到上一層軌並與前一段尾端重疊、上層淡入，做出 A→B 交叉溶接（可調秒數）。
  - **音訊依混音器輸出**：匯出的聲音會依混音器的**靜音／獨奏／音量**決定（比照播放時聽到的）；音訊與影像一律從**母素材**解碼，播放用 Proxy／逐聲道 AAC 快取不會參與匯出。
  - **MP4 位元率**：選 MP4 時可自訂**影片位元率**（Mbps）。**預設值依解析度自動建議**（像素×fps×0.12，例如 720p≈4、1080p≈7、1080p60≈15、4K≈30、4K60≈60），對話框會顯示「建議 N（依 寬×高）」。舊版一律固定 5Mbps，**4K 用 5Mbps 會嚴重壓縮、畫面像被壓過**——若嫌不夠清晰，把此值調高即可（ProRes 母帶格式則永遠固定高品質、無此問題）。MP4 的混音後音訊需重新編 AAC：**Mono 192k／Stereo 320k／5.1 640k**；完成通知會顯示檔案**實測** bitrate，該數字是交付 AAC 而非母素材的原始 bitrate。
  - **要最高畫質就選 ProRes**：ProRes 422 HQ 是**固定品質、不受位元率限制**的剪輯母帶格式（10-bit 4:2:2 + 24-bit PCM 音訊），輸出直接讀**原始母帶**、不經 proxy。若需要無損音訊，選 ProRes 或純 WAV。
  - **顯示卡加速**：MP4（H.264）在 Windows 依序嘗試 NVENC／QuickSync／AMF，在 Apple Silicon 嘗試 VideoToolbox；不可用時回退 libx264。**ProRes 一律 CPU 編碼**。來源解碼會嘗試硬體加速。
  - **怎麼確認有沒有在用 GPU**：①**狀態列右下角**顯示 `引擎：ffmpeg ✓ · GPU NVENC`／`VIDEOTOOLBOX`；②**匯出中**的進度標籤顯示實際 encoder；③**匯出完成**後顯示 ffmpeg **實際使用**的編碼器與耗時。若顯示 `libx264`，代表已安全回退 CPU。
- 再匯入影片（按鈕或拖放）時會詢問「**加入序列**（接在最後一段之後）或**取代**」——可把多支影片排在同一條時間軸連續上字幕或粗剪比對。
- **同一視訊軌內**的區塊不可重疊（不同軌之間可重疊＝疊層）；區塊間的空隙播放時顯示**黑畫面**、時碼照走。字幕時碼永遠以**時間軸**為準，不隨影片移動。
- 跨段播放會自動切換影片：原生格式（MP4/MOV）幾乎無感；非原生格式或 proxy 換段時可能短暫停頓。
- 修剪／移動可 `Ctrl+Z` 復原；專案檔會記住序列（桌面版重開自動重建；網頁版需手動重加影片）。
- 注意：加入與序列 **FPS 不同**的影片會提示警告——時碼一律以序列（第一支影片）的 FPS 為準。

### 圖片素材（PNG / JPG 等）

- 從 **🎬 影音** 匯入圖片後，它會成為一個獨立的圖片片段，預設放在播放點、建立在最上層視訊軌，預設長度為 **10 秒**。可在時間軸拖移片段、調整兩端長度、切割或刪除；圖片片段不會限制其他影音／音訊的時間軸長度。
- 點選圖片片段後，播放器會顯示**虛線選取框與四個角落控制點**：拖曳圖片中央可移動位置，拖曳任一角落可等比調整大小。完成拖曳後可用 `Ctrl+Z` 復原；若該視訊軌已鎖定，圖片不可調整。
- 要輸入精確數值時，**右鍵 →「📐 大小與位置…」**：拖滑桿會即時預覽，按 **套用** 才真的生效；按 **取消**、`Esc` 或點視窗外都會還原成打開前的樣子。**符合視窗**會維持目前的中心位置，等比例放大到上下左右**最先碰到**的那個邊界為止（位置貼齊邊緣時會先置中再算，並告訴你）。
- 圖片與一般影片可重疊疊加。圖片的位置、大小、時間與所在視訊軌會保存進 `.subtool` 專案；先放圖片、後匯入影片也會保留圖片。
- 匯出影片時，圖片會在其整段時間內持續顯示，並使用與播放器相同的位置及縮放；圖片不是只在輸出開頭出現的一格。

### 影音軌的混音（M／S／音量）

- **影音合一**：不再有獨立的音訊波形列——**混音控制（M 靜音／S 獨奏／音量）就在每條影音軌的列頭**（下方一行），波形畫在影片區塊內。
- 這組狀態與**匯出**輸出、以及右上角的浮動**混音器**面板一致；多聲道 MXF 的**逐聲道**控制請用浮動混音器（🎛）。
- 上下層（疊層／子母畫面／溶接）依**軌列的上下順序**（上面＝上層）。

### 專案音訊與解除影音連結

- 時間軸現在固定分為：**視訊軌（上）→ 音訊素材軌（中）→ 字幕軌（下）**。匯入新的影音或音檔時，音訊素材可自行超出影片結尾，純音訊專案也能正常播放與匯出。
- **每個音訊素材只有一個片段**：在片段上按右鍵可選擇顯示 `MIX` 或其中一條來源聲道的波形；這只改變觀看的波形，不會改變實際輸出。
- **音訊右鍵選單**：影片原音、外部音檔、音訊列空白處與左側列頭都可開啟「📂 在檔案管理器中顯示」及「🎧 音訊配線…」。音訊軌鎖定後仍可定位檔案、辨識、靜音、配線與切換波形；會改變時間軸的切割與移除則不顯示。
- **解除影音**：選取影片片段後按時間軸工具列的「🔗✂ 解除影音」，或右鍵選「解除影音連結」。完成後會新增一個原音音訊素材，影片原音自動關閉；兩者之後可各自拖移、修剪、`Ctrl+K` 切割或 `Del` 刪除。首次處理 MXF／MOV 可能需要等待 ffmpeg 建立音訊快取。
- **聲音開關**：音訊列左側與每個音訊片段的喇叭可直接切換；`🔊` 為開啟、`🔇` 為靜音。這不會刪除素材，也會影響預覽與匯出。
- **專案輸出聲道**：從「配線／音訊通道設定」選擇總聲道數與 Mono、Stereo、5.1 分組，再為每個來源指定要送到哪幾條專案 bus。混音器顯示的是**專案輸出軌**，不是單一檔案的聲道。
- **輸出**：影片匯出會帶著配置後的音訊。WAV 預設會依 A 軌順序把全部專案 bus 輸出到**同一個 WAV 檔**；在該交付列按「⚙ 音軌」後，可選取要輸出的 bus／群組與順序，例如只選 A7、A8 即輸出為 Stereo 的左、右聲道。

### 語音辨識／文本匹配生成字幕

1. 在要處理的**影片原音或外部音訊素材列上按右鍵**，選「🎙 語音辨識／文本匹配…」。工作台上方會列出本次真正要送出的素材與長度，先確認沒有選錯；可選的「辨識音訊來源」就在檔名下方。文本匹配的寬視窗會把逐行文字稿和辨識引擎並排，窄視窗則自動改成單欄，不會出現水平捲動。
2. 若素材有多個可獨立讀取的來源聲道，先選「辨識音訊來源」：

   - **全部來源聲道混音**（預設）：把素材的所有實際來源聲道等權平均成 mono；例如 8 軌素材就是 8 軌一起平均，適合對白可能分散在不同軌的情況。
   - **最後兩軌組**（三軌以上才顯示）：只取依來源座標排序後的最後兩軌，例如「來源聲道 7 + 8」。這只是明確的軌號組合，不代表程式判定它一定是 Stereo；素材恰好只有兩軌時，它與「全部」完全相同，因此不重複顯示。
   - **來源聲道 N**：只分析指定的一軌，適合已確定某軌是乾淨對白時使用。

   選擇只影響**本次**送入所有辨識引擎的音訊，不會改變播放、波形、專案音軌、bus 配線或輸出。若多個項目其實只是同一份不可拆的單聲道快取，程式不會顯示無效的單軌選項。
3. 從「工作方式」的兩張模式卡選擇：

   - **語音辨識**：由聲音產生字幕文字與時間碼，維持原有流程。
   - **文本匹配**：貼入已校對、已分行的純文字稿；程式只分析聲音並匹配時間碼，裁掉每行首尾空白後，字幕文字完全以原稿為準。

   文本匹配會把**每個非空白行固定視為一條字幕**。可直接貼上，或按「匯入 TXT」載入大量逐行文字稿；文字框上方會即時顯示有效行數。TXT 沿用專案的文字解碼器，自動辨識 UTF-8、UTF-16LE、UTF-16BE 與 BOM。程式會忽略純空白行並裁掉每行首尾空白；除此之外，同一行即使有多個句號也不會再拆分，不同兩行也不會合併，文字與標點都不會改寫。首版一次只能處理一個影音／音訊素材，避免把同一份稿件重複套到多個來源。文字稿只用於本次工作，不會存進語音辨識設定。
4. 選擇「聲音分析引擎」。畫面只會顯示該服務真正支援的提示欄位：

   | 模式 | 顯示的導引欄位 |
   |------|----------------|
   | Google Gemini | 一般提示詞（Prompt） |
   | Azure Speech | 專有名詞 Phrase List；不是一般指令 |
   | ElevenLabs | 專有名詞導引（Keyterms） |
   | Groq／OpenAI | 前文與專有名詞導引（Prompt） |
   | 本機 AI | 不顯示也不使用 Prompt；只需選模型與語言 |

   ElevenLabs Scribe v2 與 Azure Fast Transcription 是專門的語音辨識服務，會回傳高精確逐句／逐字時間碼與說話者標記（Diarization）。OpenAI Whisper-1 與 Groq 也會同時要求 segment、word 時間；一般語音辨識可保留供應商句界，文本匹配則用逐字位置決定固定原稿各行的 In／Out。本機 AI 改用 `_timestamped` Whisper 模型並要求逐字時間，會先修補零長度與倒退的 word timestamp，再依標點、停頓、最長顯示時間與字數組成字幕段。Gemini 仍主要提供模型估計的句級時間。

   若整體精確詞覆蓋至少 90%、漏句不超過 `floor(總行數 × 5%)`、每個連續漏句區段不超過 5 行且沒有時間重疊，程式會保留原本可靠的時間；有部分逐字證據的行優先使用真正的 word timestamps，其餘零證據行只在前後可靠錨點間產生受閱讀速度限制的短時間碼。這種結果會標成**需人工校對的完整初稿**，不是精準對齊。

   若連續漏句超過 5 行、缺少任一側可靠錨點、整體漏句比例過高，部分句子的時間碼有重疊，甚至聲音分析引擎整次失敗，程式仍會建立**句數完全相同的完整原稿軌**。能安全匹配且在專案 FPS 吸附後仍有效的行保留時間碼；其餘各行保留原文字、原順序與原編號，顯示為 `--:--:--:-- → --:--:--:--` 的無時間碼字幕，讓使用者之後自行設定 In／Out。程式不會填入 0–1.5 秒之類的假時間，也不會因單句失敗而刪掉後續句子。這項行為位於共用文本匹配層，因此本機、Groq、OpenAI、Azure Speech、Google Gemini 與 ElevenLabs 全部一致。

   失敗或需校對面板會直接列出「無時間碼行號」；字幕清單仍保留所有行，無時間碼字幕在補上 In／Out 前不會出現在時間軸、影片預覽或影片燒錄中。Encore 與 Excel 匯出可保留 `--:--:--:--` 佔位符。需要除錯時可主動匯出匹配診斷 JSON；該檔包含完整逐行稿件、辨識文字／逐字時間與所選來源座標，但不含從素材／設定帶入的名稱、路徑、URL、API Key、HTTP 標頭或音訊，也不會自動上傳。稿件或辨識台詞本身若寫有路徑／網址字樣仍會原樣保留，分享前須檢查完整文字內容是否可公開。
5. 若選 **Azure Speech**，請在 Azure 建立 **Speech resource**，填入該資源的 **API Key** 與 **Region**。API Key 欄右側可暫時切換「顯示／隱藏」以便核對；這裡不能直接輸入 Microsoft 帳號密碼，Key 與 Region 必須來自同一個資源。
   - 新設定預設使用 `japaneast`；若資源建立在其他支援區域，請依 Azure「金鑰與端點」頁面顯示的 Region 填寫。既有自訂 Region 不會因升級被覆蓋。
   - Key 會與其他語音服務 Key 一樣保存在這台電腦的 SUB Tool 設定中；共用電腦使用完請移除。
6. 若選 **ElevenLabs**，請填入 ElevenLabs 帳號的 **API Key**（支援 Scribe v2 語音辨識服務）。「Keyterms」欄位可用逗號分隔專有名詞、人名或專門術語，例如 `SUB Tool, Evan`，協助模型在多語言與專有名詞環境下更精準辨識。
7. 使用 Azure 時，已知語言請明確選 **繁體中文**（送出 `zh-TW`）或**英文**（送出 `en-US`），通常會比自動偵測更準。「語言」是**音訊實際說的語言**，不是翻譯目標；Azure 這條流程不會把英文自動翻成繁體中文。
8. 使用 Azure 時，「Azure 專有名詞」可用逗號分隔人名、產品名或縮寫，例如 `SUB Tool, Evan`。這些詞只用來提高辨識機率，不是一般提示詞。

OpenAI／Groq 的長音訊會自動切成最長 10 分鐘、相鄰重疊 10 秒的區塊，每個未壓縮 WAV 都低於 20 MB；程式會比對重疊區兩次辨識的完整逐字序列與時間，文字與時間能唯一對應時會合併小幅時間碼抖動造成的重複，遇到同字候選不唯一則保守保留，避免刪掉台詞中真的連說兩次的字。桌面版會在**按下辨識／匹配後**，把每段已完成來源聲道混音的 WAV 暫時壓成 16 kHz mono、64 kbps MP3 再上傳，成功或失敗都清除磁碟暫存；母素材、播放、波形與輸出不會改動。若 ffmpeg 壓縮不可用，或使用網頁版，會自動退回同一套安全 WAV 分段，不會退回只辨識第一軌。

**背景執行與進度監控**：
- **縮小至背景**：辨識或匹配啟動後，對話框會出現「縮小至背景」按鈕；點擊後遮罩關閉，您可回到主介面自由播放預覽、縮放時間軸、編輯既有字幕與操作快捷鍵，背景推論持續執行不中斷。
- **頂部進度指示器**：背景執行期間，頂部選單列會顯示帶有脈動光環與即時百分比的「🎙 辨識中 45%」按鈕；滑鼠懸停可查看詳細狀態，點擊可隨時打開進度監控視窗。
- **隨時取消與自動注入**：進度視窗中隨時可點「取消工作」安全中止推論；辨識完成時會自動在時間軸新增專屬字幕軌並跳出通知。

辨識進行中仍可按 **取消**；為避免誤觸中斷，點視窗外不會關閉工作。開始後設定欄位會鎖定，失敗時才恢復編輯；若正在準備暫存 MP3，取消也會終止對應 ffmpeg，已取消工作的晚到結果不會上傳後續分段或寫進字幕軌。本機 AI 在第一個 29 秒推論段完成前會顯示「運算中」，雲端引擎在沒有可量測百分比時則顯示持續活動的進度條，不會用固定數字假裝進度。解碼時會列出目前段落、token 數與經過秒數，之後再依真正完成的分段更新百分比。狀態中的「GPU」代表 WebGPU 加速確實啟用；若顯示「CPU」，代表顯示卡不支援或 WebGPU 載入失敗，程式已自動改用 WASM。取消本機 AI 會終止該次推論與模型工作階段；已下載的模型檔仍留在瀏覽器快取，下次可重新載入。

Whisper Small 逐字時間版首次約需下載 **CPU 240 MB／GPU 560 MB** 模型資料；Large v3 Turbo q4 逐字時間版約為 **800 MB**，是速度與相容性優先的量化版本，不代表一定比 Small 準。切換到逐字時間版後第一次需重新下載一次模型；之後會沿用快取。Whisper 的 word timestamp 是模型推估值，不是聲學保證；選擇「繁體中文」時，各辨識服務回傳的中文字會在保留原時間碼的前提下轉成台灣繁體用語，這只能修正簡繁字形與用詞，不能把聽錯的人名或台詞自動變正確。電影配樂、多人重疊或收音較差時，本機模型仍可能誤聽；重要成品建議抽查字幕邊界。

Azure 同步 Fast Transcription 目前以官方 GA REST 規格的較嚴格限制為準：單次音訊需**短於 2 小時且小於 250 MB**。更長素材請先在時間軸切段後分次辨識。服務回傳的毫秒欄位是時間資料的解析度，不代表聲學邊界一定精準到 1 ms；重要成品仍應抽查人名、漏字與字幕 In／Out。

### 時間軸（多軌道）

- **時間尺／波形**按住拖曳＝移動播放點；時間尺採 36px 高、深灰底與高對比刻度，方便頻繁點按跳轉。點軌道**空白處**＝取消所有選取。
- **影片與音訊素材區塊不會在滑鼠停留時跳出整塊資訊框**，避免遮住波形、字幕與播放點；素材名稱仍直接顯示在區塊內，移動、修剪及聲道／波形等操作請使用區塊邊緣或右鍵選單。
- 暫停後連續跳轉或按 `←`／`→` 逐格時，播放器會以**最後一個播放點**為準更新，不再先等待前一個尚未完成的定位。素材本身的解碼速度仍取決於編碼與關鍵影格間距。
- **只有按住左鍵不放拖曳**才會框選多句字幕。
- 拖曳字幕區塊＝移動（上下拖可**換軌道**）；拖左右邊緣＝調整起訖。拖移時會**磁吸**到播放點與其他字幕的邊界，且同軌字幕**時間碼不會重疊**。
- **複製字幕**：按住 `Alt` 拖曳字幕區塊，會複製原字幕到滑鼠放開的位置；多選字幕時會整組複製。`Ctrl/Cmd` 拖曳的既有複製操作仍可使用；拖曳左右邊緣調整時間不會複製。
- 左欄：`＋軌道` 新增、`✕` 刪除、`👁` 顯示/隱藏、**雙擊名稱可改名**；軌道過多時側邊出現上下捲動條。
- 每軌都可放字幕，**匯出時可勾選要輸出哪些軌道**。
- **輸出範圍**：播放器的 `[ In ]`／`[ Out ]` 用來設定部分匯出範圍，`✕` 清除。三個動作都會寫進 **🕘 動作紀錄**，可用 `Ctrl+Z`／`Ctrl+Shift+Z` 復原／重做。
- **🕘 動作紀錄**：開啟清單，可逐步復原(`Ctrl+Z`)／重做(`Ctrl+Shift+Z`)，點清單任一步可跳到該狀態。
- **📌 備註**：`M`、`V` 或 `＋ 新增` 會在**目前播放時間點**建立空白備註標記，不會開啟備註面板或把游標切到文字欄，因此可以直接繼續播放與剪輯；每項可**打勾**表示已確認，點該項的**時間**會把播放窗與時間軸跳到該時間點。
  要補寫內容時再開啟備註面板，雙擊「（雙擊輸入備註）」即可編輯；空白備註會一直保留這個可點擊提示，
  隨時**雙擊**就能補上或修改。

### 安全框（構圖參考線）

- 播放器工具列的 **⊹ 安全框** 鈕：開啟後在預覽畫面疊上 **100% 邊界**、**90% 動作安全框**（白實線）、**80% 字幕/標題安全框**（黃虛線）與**中心十字線**，方便對位與構圖。**只是預覽參考，不會燒進匯出**；開關狀態下次開啟程式仍記得。

| `↑` / `↓` | 選取影片段時：切到上／下一段（播放頭跟到段首） |
| `Del` | 刪除選取的影片段 |
| `Backspace` | 關閉選取影片段前方的空白（左移貼齊前一段結尾） |

---

## 四、字幕格式

- **匯入**（自動偵測 UTF-8 / UTF-16 / 含 BOM）：SRT、ASS/SSA、Adobe Encore（`HH:MM:SS:FF`）、純文字。
- **匯出**（一律 **UTF-16 LE 含 BOM**）：SRT、ASS、Adobe Encore、純文字。
- Adobe Encore 是「影格」時碼，請先在右上設定正確 **FPS**（桌面版會自動偵測）。
- 舊檔在網址以外使用 `//` 或兩個反斜線代表換行時仍可匯入；網址中的
  `https://` 與路徑內雙斜線會原樣保留，不會再被拆成多行。
