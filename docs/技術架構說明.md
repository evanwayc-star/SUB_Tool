## 0. 鐵律（Invariants）

### 0.1 三路一致：預覽 ＝ mpv ＝ 匯出燒錄

軌道樣式、常用樣式與逐句覆蓋由 `substyle.js` 的 `effStyle()` 合成。HTML 用 CSS adapter，mpv／libass 與 ffmpeg 燒錄用 ASS adapter。新增欄位在同一處定義預設值與繼承，再比較三路畫面。

### 0.2 字幕縮放基準是畫面高 ÷ PlayResY

ASS 畫布固定 1920 × 1080。字級、框線、陰影、字距、行距與座標依 `outputHeight / 1080` 換算。HTML 保留小數像素，底框隨文字縮放。使用寬度比例或固定最小像素會讓非 16:9 或小預覽偏離燒錄。

橫排 face 度量有效時，ASS 依 em、OS/2 Win ascent／descent 換算字級，依 HTML 行盒／基線定位。缺度量沿原 ASS 表達。原字級、換行及 cue 由自產 metadata 保真。

### 0.3 ASS Fontname 是字型檔內部家族名

`font/<資料夾名>/` 提供 UI 名稱。ASS Fontname 填字型檔解析出的 family。指定錯誤時 libass 可靜默 fallback，須用實際字形驗收。

### 0.4 Windows filtergraph 路徑要跳脫兩層

磁碟代號冒號與反斜線經字串及 ffmpeg filter 兩層解析，例如 `C\\:/...`。排查時重用 `spawn` 的實際 argv，避免 shell 的額外解析。

### 0.5 時間域：外部是時間軸時間，播放器是來源時間

字幕、播放點、片段 offset、In／Out、備註及交付共用時間軸秒數。序列層 `sequence-time.js` 統一映射影片與外音。Media adapter 將容器時鐘換成來源秒數，事件換回時間軸後才通知 UI。

```text
elapsed      = (timelineTime - clip.offset) * speed
sourceTime   = reverse ? clip.out - elapsed : clip.in + elapsed
timelineTime = clip.offset + (reverse ? clip.out - sourceTime : sourceTime - clip.in) / speed
```

來源原點、反轉區間與裁切末格見 [FPS I4](FPS_時碼一致性.md#i4-靜止讀數同源於-mediadisplaytime)。

### 0.6 有產出不等於正確

| 驗收對象 | 完成證據 |
|---|---|
| 交付 | ffprobe 規格與實際片長，解碼像素、字幕位置、聲道及 PCM |
| 定位或截圖 | 同一請求、目前可見 presenter 的目標格與同時點疊層。Electron 頁面截圖取不到 mpv 原生子視窗像素 |
| 共用公式 | 先用邊界案例驗規則，再驗兩端輸出一致 |
| 建置 | `tests/sourceEntryHtml.test.js` 核對 Vite 原碼入口。v6.1.7（`dbc047b`，`074572d` 還原）及 v6.1.9（`9544570`，v6.1.10 還原）曾遭 asar 解檔覆蓋，build 仍成功 |

驗收操作以[開發與驗證](開發與驗證.md)為準。

### 0.7 顯示狀態看 computed style

CSS `display` 可覆蓋瀏覽器的 `[hidden]` 預設。對有明訂 display 的元素補隱藏規則，驗收讀 `getComputedStyle()`。

### 0.8 音訊素材、專案 bus、輸出 stream 是三層

`project-audio.js` 依 placement 的來源 stream／channel、route、gain 解讀單聲道專案 bus，再按交付編組輸出 Mono、Stereo、LtRt 或 5.1 stream。三層各有身分與數量。交付只帶母素材，main 另外拒絕 Proxy、播放快取與波形路徑。

### 0.9 靜態圖片也是時間軸片段

圖片擁有時間範圍、軌道、幾何及淡化，作用期間每格都參與合成。Windows mpv 的透明 guide 顯示疊層與控制點，永久穿透滑鼠。主 renderer 的 `#imageLayer` 與字幕互動層是單一互動入口。

## 1. 執行架構

Vite 與 `vite-plugin-singlefile` 將原生 ES modules 打成 `dist/index.html`。網頁與 Electron 共用 renderer，經 `window.subtool`／`IS_DESKTOP` 選擇 adapter。

### Renderer

`main.js` 載入樣式與 `app.js`。app 組裝 DOM、ticker 與跨領域訂閱。模型經公開函式呼叫，下層透過 `events.js` 通知組裝層。介面契約涵蓋時間域、呼叫順序、取消資格與失敗結果。

### Electron

| 問題 | 先查 `electron/` |
|---|---|
| IPC 或路徑授權 | `preload.js` 限制 `window.subtool`，`main.js` 組裝 handler，`file-authority.js` 核准讀寫 |
| 來源與原生播放 | `media-probe.js` 管探測程序，`mpv-host.js` 管視窗、來源 session、時鐘與畫格 |
| 背景轉檔及波形 | `media-intake-runtime.js` 管 Proxy、聲道、串流 lease。`continuous-source-waveform.js`、`continuous-waveform-cache.js` 管連續 PCM 與進度，`source-waveform-cache.js` 管片段快取，`source-waveform-worker.js`／`source-waveform-task.js` 管 I/O 與完成屏障 |
| 交付 | `export-queue.js` 排程，`delivery-runner.js` 執行，`export-plan.js` 編譯，`export-artifact.js` 驗證，`export-watchdog.js` 裁定終態 |

新建預覽 Proxy 最高 720p、4000 kb/s 目標、最快 preset、無 B 幀、短閉合 GOP。硬體失敗等原 writer 結束，才以新 generation 重試。已發布的串流維持原輸出。[Proxy 的 GPU 路徑](Electron_維護手冊.md#proxy-的-gpu-路徑)

### 專案儲存與對話框

#### 開啟意圖與資料准入

1. `Project.open()` 在確認、picker、IPC 或引擎等待前捕獲意圖。新開啟／新建／取消撤銷舊讀取。真正 reset／apply 前重核資格與丟棄同意，期間若有新提交需再確認。
2. 先驗根物件、record、文字型別及安全整數索引，再換工作區或提示缺字型。按 schema 判斷軌索引基數。合法數字字串、負值、缺值或 null 依原遷移語意處理。字幕、備註與軌名有明確非字串值則拒絕。
3. 依宣告、records 與引用建軌，兩類軌合計可補最多 1,024 筆未宣告空軌，完整軌陣列可超過此數。拒絕 `cues:[null]`、超界索引或過量補建，保留原工作區。接受 FPS 後正規化定時 cue 數值與格網，再設 History 基準。

#### 存檔、dirty 與媒體復原

| 時機 | 所有權與結果 |
|---|---|
| 手動存檔 | `save()`／`saveAs()` 立即凍結已提交內容並依序寫入。成功寫出的同一快照成為儲存基準。另存／開啟／新建由 `project:identity` 更新名稱與路徑。舊工作的完成不得覆寫新工作區 |
| dirty／自動備份 | 空軌、格網、樣式與範圍皆算內容。播放點、縮放、探測出的來源 FPS 不算 dirty。只備份與原檔、上次成功備份不同的同一份快照。失敗可重試，完成時重核工作區、目標與手動存檔次數 |
| 格式 | `shared/text-encoding.cjs` 管專案、備份及文字匯出的 UTF-16LE BOM，讀回相容 UTF-8、UTF-16LE／BE 與舊無 BOM；typed array 尊重自身範圍。XLSX、快取及內部協定各走其格式 |
| 載入 | `ProjectLoadSession.restoreMedia()` 在第一個 await 前建初始文件基準，依序復原主素材、placement／固定幀、外音、播放點。metadata 補入對應既有快照。第一次成功呈現才消耗保存位置，使用者較新 seek 優先 |
| 離線、取消、重連 | 保留未交接 record，可存檔／重試。成功逐筆交給 runtime／History，避免重複路徑誤去重或已刪項復活。換工作前交接剩餘資料及既有基準；舊工作只清理自己未交接的 URL／lease。主素材經 `Project.continueLoad()`，stat 與 loader 每次等待都核對資格 |
| 舊專案沒有來源 ID | 註冊時取該次原始配線。原 placement 唯一、名稱與正數大小相符、沒有較新的成功存檔且計畫仍有效，才把 ID 和預設配線補回對應基準／History。舊檔缺完整內容雜湊，歸屬不明時保留原儲存基準 |
| 外音與交付 | 外音待重建資料依 record 逐筆收放。網頁 File 依原 History 快照用 WeakMap 保存。`Project.unrestoredClips()` 供交付判斷範圍內缺件，隱藏影片仍查聲音。首次加影片保留既有圖片、外音與背景工作，取代影片或換專案才完整 reset |

#### 對話框及延遲命令

- `openModal()` 回傳 session。每次開窗重設內容捲動與拖移，只讓中段捲動；完成後用 `isCurrent()`／該 session 的 `close()`。一般關閉走 `onDismiss`，取代走 `onReplaced`。浮動面板以 `togglePanel()`／`closePanel()` 同步焦點、開啟 token 與 `aria-expanded`。
- 延遲操作固定原工作區、物件、世代、相關欄位與鎖定。Undo 重建同一 ID 會撤銷舊操作。覆蓋、刪除及全軌確認還須核對原集合。清快取固定母路徑；批次 trim 只查同軌鄰片。
- 字幕／備註匯出保存原軌物件，確認時解析新索引，從 `History.committedSnapshot()` 及 `snapshotProvisionalCueEnds()` 生成成品。`prepareSubtitleFileExport()` 成功備妥全批才關窗，重複寫出共用完成結果。SRT 空白分隔由 `SubFormats.parseSRT()` 處理，保留句內換行與空格。
- 列表時間輸入保留原兩端點、格網、草稿與焦點。重繪／排序不移動有效 editor。字幕匯入 FPS 留在草稿，目的軌確認才和字幕一起提交。
- 快捷鍵每次變更更新草稿 revision，匯入含取消皆取代舊讀取；三欄保留空槽，僅儲存／匯出複本走 `stripEmptyBinds()`。持久化成功才套用凍結草稿，等待時鎖住操作。
- 輸入法組字 `isComposing`／`keyCode:229` 保留 Enter、Esc、方向鍵。`setupTimecodeInput()` 在 capture 階段保護動態輸入；時碼貼上固定原值、選區、焦點與世代。選單用 `aria-activedescendant` 保留 editor，滑鼠工具列操作釋放焦點。
- `keyboard.js` 依最上層視窗或目前面板決定 Enter 的作用範圍。對話框 footer 以 `enterDefault: true` 明示預設確認，階段變更時用 `setEnterDefault()` 切換按鈕與 ↵ 提示。範圍內恰有一個可見且可用的預設按鈕時，單按 Enter 才會執行。右鍵選單保有該層按鍵，收起後回到原欄位。[使用說明](使用說明.md#11-常用快捷鍵)

#### 字型與樣式庫

- `loadFonts()` 整批註冊完成才換入 family、度量及 FontFace，只釋放自己持有的 face。掃描失敗保留完整舊對照，可重試；部分失敗保留同一套舊 face、檔案及度量。缺字型用載入後的實際字寬驗證。
- 常用樣式以內建／自訂、明確群組、名稱識別。套用前以 `STYLE_DEFAULTS` 補齊外觀；逐欄 patch 只改明示欄。專案 `usedPresets` 同名同樣式重用，衝突以「名稱 (專案)」「名稱 (專案 2)」補入。批次檔名淨化後分配不分大小寫的唯一名稱。
- 匯入固定 modal 和 request revision，較新取消也撤銷舊讀取。儲存同步發布已接受快照，等持久化結果才提示成功或更新字幕。失敗只回復原工作持有的快照，保留較新修改。`presets:changed` 刷新管理視圖。

### 音訊配線編輯

`AudioRoutingModel` 的根 session 持有基準、草稿與巢狀輸出還原點。專案 adapter 即時預覽，交付 adapter 只改該列。根確認一次 History，取消還原。來源在編輯期間登錄時，把同次分配併入父／子基準與草稿，保留背景新增 bus。

交付候選始終包含全部 bus。輸出有序子集、Stereo／5.1 聲道及 WAV 選軌直接保存 bus ID；明確縮減 bus 才修剪配線。bus 與輸出 stream ID 持久化為字串，遞增採精確整數。

### 預覽與 History

| 操作 | 提交規則 |
|---|---|
| live 預覽 | `History.committedSnapshot()` 投影已提交值給 Undo、存檔、備份、dirty 與交付。確認解除 projection 後記一次；取消僅還原自己最後寫入的欄位。reset／Undo／Redo 先取消草稿、DOM、聲音及 listeners |
| 打點與時長 | `snapshotProvisionalCueEnds()` 以同次已提交的格網／片長收尾，越過片尾沿 In 語意補兩秒。已接受的位移、修剪、時長等編輯接手暫定 O；取消不消耗。在重繪及 History 前，`extendDurationForCues()` 只依本次接受的定時字幕延長 |
| 片段手勢／速度 | 先核對所有物件、所動欄位、兩層鎖與受影響鄰片，再進行 ripple 或覆蓋確認。`setClipSpeed()` 等方向及實際畫格完成才記一次。取消保留新 seek 與背景修改 |
| 字幕／備註 | `beginCueEdit()` 以欄位比對合併不同欄的背景編輯，同欄衝突拒絕全批。切分先驗文字、時間及樣式。列表上下鍵保留文字遊標。批次備註採原物件、內容與 IN，整組一次提交，同時點既有備註保留 |
| 即時樣式／音量 | `recordCoalesced()` 只合併同 owner 的頂端紀錄，回到原值移除空步驟；500 ms 只結束合併期。Mixer 讀取 bus，重繪不建軌。音量交易固定 bus、世代與原增益 |
| 時碼／比對 | `tcparse.js` 對不完整或非法輸入回傳 `null`；真正輸入中保留焦點與草稿。比對定位與套用檢查快照 revision 與目前計畫列／配對，著色與隱藏均用 `row.active` |

### 交付計畫與成品階段

- `delivery-submission.js` 同步凍結已提交專案、列 revision、目錄與規格。逐列 ACK 後只回收未改原列，失敗／取消保留未收項目供重試。`prepareDeliveryPayload()` 與 `buildDeliveryArgv()` 共用格式、音訊、TC、有效片長。佇列存 SMPTE 分號 TC，編譯 filtergraph 才轉句點。
- 影片章節由已勾選的 `kind:'note'` 快照產生。`shared/delivery-chapters.cjs` 換算輸出相對時間，處理同時點及開頭；舊混合標題歸屬不明時要求重建。H264-MP4 經編碼。`subtitle-audit.js` 檢查整個區間內的重疊。
- 切割、trim、交付範圍保留原始淡化時鐘。溶接只接受有限正值，上限為兩片段變速後時長的較小值。隱藏影片仍依配線交付聲音。48 kHz bus 在 delay 後以 `asettb=1/48000,asetpts=N` 建連續整數 sample 時鐘，再裁切。
- 每份交付有自己的程序。watchdog 持有 stage、lease、程序與終態，artifact 組裝並驗證內容。光碟製作完成才達 100%。航空／MOD 後處理在開檔前、handle、開檔後核對 BigInt dev／ino；關閉無法確認時保留 stage 與 lease、回報 cleanupError。[ADR-0001](adr/0001-每份交付各自一個-ffmpeg-程序.md)

### 音訊效果與背景工作

#### 來源、效果與配線

- `audioLimiterSpec` 隨來源保存（含各 stream 量測）。`shared/audio-loudness.cjs` 正規化。預覽／交付從完整母 stream 套效果，再拆聲道、裁切、gain／fade。Peak 限制器補償預讀並沖出尾端。
- `audio-effects.js` 同來源以最後操作為準，不同來源可並行。準備、安裝、History 提交及同步通知後重核來源、母路徑與世代。失敗保留既有效果；Undo／Redo、重開、遺失快取依保存規格重建。
- 以 probe 的實體 stream／channel 為準，保留既有配線並提示缺少對應；母素材指紋、配置、規格及成品須吻合才重用效果。已有效果時，晚到母音只供還原。只清理本工作未交接的私有 WAV。
- 瀏覽器先安裝來源音訊與配線，再解碼波形。多 stream 先展開，短尾補零。無聲 Proxy 的抽音完成若仍持有來源與播放意圖，從當前來源時間起播，有 pending seek 交給原呈現請求接手。

#### 播放聲音的唯一 owner

| 交接點 | 必須具備的證據或清理責任 |
|---|---|
| 選擇畫面來源 | `Media.previewState()` 顯示實際模式、來源與等待原因。正向流暢模式可用同資料夾 Proxy，原片模式用母素材；歸零 Proxy 不繼承母素材偏移或改寫其 duration。反轉／倒帶含準備與 fallback 期間停用模式切換 |
| 接受 play 或 seek | `media-presentation-core.js` 持有畫格請求、最新意圖及 hold。`media-playback-runtime.js` 持有配線、作用中片段、外音與 tick。seek 先停 follower，收到目標畫格才按最新意圖準備。取消先撤銷資格再停止聲道 |
| 準備聲道 | `AudioEngine.prepareElements(sourceTime, timelineTime, { owns })` 對整組原音、外音與 overlap voice 固定同一目標。等待定位結束且 `readyState >= 3`，上限十秒。準備結果為 ready／cancelled／failed。只有仍有效的 ready 計畫可 `commit()`，整組起播一次並等待所有 Promise。任一失敗只停止自己持有的整組 |
| 接受 presenter 起播 | HTML 等 `play()`；有 element／buffer follower 的正向 mpv 要同來源 `{ready:true, sourceTime}`。Host 在命令 ACK 後查 pause、seeking、core-idle、片尾、時鐘。以接受時同一來源與時間軸座標起播；跨活動邊界或容差最多重備整組一次，等待期間停用 drift tick |
| 正播再緩衝 | 已確認來源的 `core-idle`／`paused-for-cache` 可只停 follower、保留意圖與 mpv 讀取。解除緩衝須重過 readiness，含提交途中的聲道都只恢復一次。同一批 mpv 位置觀測只作一次漂移校正 |
| Native 音交接 | 只有同源替代聲道可抑制母音。等待 mpv 靜音 ACK 才起播快取；反之等監聽混音 ACK 才解除總靜音。快取前按來源 stream／channel 與 `ProjectAudioInterpretation` 套 M/S、增益、零音量及路由，外部配音不會關掉主片 |
| 原生方向與反向首播 | 方向命令失敗保留時間軸目標、停止並讓下次重設。反轉 Proxy 首播停鐘用實際相鄰 PTS／速度的持格期限加一秒判斷，最多重載一次，證明時鐘前進才接回聲音；失敗暫停提示 |
| 重疊、反向、解除影音 | 每個 placement 有獨立 voice、速度、時鐘、淡化、trim out，共用來源資產及配線。反向音訊在裁切後反轉／變速。交接前停舊 clone。解除影音等待時同來源配線被改就撤回整批；新來源按登錄當次取得設定 |
| 音量表 | 同一 bus 的 WebAudio 聲道同次取樣逐 sample 加總，原生由同時窗 PCM 求峰。混用不同取樣時鐘顯示「—」，−60 至 0 dBFS 共用刻度。`native-audio-meter.js` 一次一個請求，暫停／換源／接管撤回舊結果 |

定位與呈現的時序及反例見 [FPS 呈現生命週期](FPS_時碼一致性.md#3-呈現生命週期)。

#### Proxy、聲道與取消

1. `media-intake-jobs.js` 核對工作區、session、request 及來源 key。stream completion 可早於 IPC／metadata，只安裝一次；可播 URL 與最終成功分別判定。重試只重做仍缺項目。
2. worker 保存 PCM 及 checkpoint 後發布連續 100 Hz 峰值。renderer 核對整數 sample 與桶邊界，未完成尾段留白。一般背景聲道沿用正式 `wave.wav`，合成或倒帶需要畫面時可在波形完成前排入影片工作。舊 bridge 走分段入口。[播放與波形調度](Electron_維護手冊.md#媒體-intake)
3. mpv／可直接播放的素材可先提交。需先 intake 的 HTML 來源由 `provisional-source-waveform.js` 顯示唯讀來源波形；待正式 metadata 與來源 key 重驗後才交接片段。暫圖不建立播放點、History 或交付。效果與 MIX 的既有峰值不可冒充個別聲道。
4. 個別聲道按 stream／channel 獨立取得。`waveform-decoder.js` 讀取已驗證的顯示峰值，舊有原音 WAV 可產生峰值快取。WAV 轉峰值以約 5 ms 預算分段，每次繼續與發布前核對資格。來源及成品驗證見 [Electron 媒體 intake](Electron_維護手冊.md#媒體-intake)。
5. reset／停止先在 renderer 撤銷 owner，再通知 native 收尾，完成前的 writer 由 native 負責。停止可保留重試紀錄；首次在外音專案加影片保留外音工作。取消 Proxy 不切斷已提交素材的 mpv 時鐘。成功換源才釋放舊 lease。

### 人聲波形的顯示邊界

`Wave` 保存 100 Hz min/max 與 MIX／聲道／人聲選擇，依 placement 裁切、變速、反轉投影。即時取樣只接受可隔離的單一正向來源、增益前訊號，避免混入 master。顯示資料獨立於 State、History、播放、效果與交付。

| 階段 | 契約 |
|---|---|
| 讀 PCM | `vocal-waveform-source.js` 從母素材讀 44.1 kHz 立體聲，30 秒中心、前後各 2 秒，按 stream／channel 還原後才混音；成功 EOF 按位置補零 |
| 排程 | 同母素材切片共用推論與訂閱，最後一人離開才取消。單 Worker FIFO 含 PCM 讀取，取消中的工作收尾後准入下一份。全部完成才提交選擇 |
| 模型 | 固定 SHA-256；IndexedDB open、upgrade 與 transaction 共限 1.5 秒，逾時視為未命中。命中和下載皆驗雜湊。[模型研究](research/人聲波形模型研究.md) |
| 結果快取 | 本機 IndexedDB 驗來源、模型、stream、片長與演算法。桌面可辨識的 NAS 母檔另存峰值到 sidecar，以共享檔案身分取代本機路徑指紋，校驗峰值長度、數值與摘要。新操作或 reset 撤銷還原。桌面 stat 加前中後取樣無法辨認未取樣區的等長變更。指紋完成前選擇只保證本次有效 |

## 3. 核心資料

### State

| 資料 | 持久內容 |
|---|---|
| `tracks`／`cues` | 字幕軌、內容、時間及樣式 |
| `videoTracks`／`clips` | 視訊軌與影片／圖片配置 |
| `projectCanvas` | 自訂畫布寬高，`null` 表示依素材自動決定 |
| `audioProject` | bus、來源配線及輸出編組 |
| `externalAudioState` | 外部音訊的序列化配置；runtime 素材由 Media 持有 |
| `notes` | 備註文字及時間 |
| `fps`／`dropFrame` | 專案時間基準 |
| `viewStart`／`pxPerSec` | 時間軸視窗與縮放 |

選取欄位只能經 `setSelection()`、`deselect()`、`pruneSelection()`、`focusTrackKind()` 修改。Media 的內部欄位也只能由明列內部模組存取；其他 caller 使用 `activeClip()`、`inGap()`、`mpvPresenting()` 等公開查詢。兩道 lint 圍籬的例外以 `eslint.config.mjs` 為準。

### Cue

字幕保存 `id`、`start`、`end`、`text`、`track` 與可選逐句 `style`。`timed:false` 明確表示沒有可信時間碼，不能補成假的定時字幕。

### Clip

片段以 `offset`、`in`、`out`、`vtrack` 表達來源範圍及時間軸配置，另保存速度、反轉、淡化、幾何與來源身分。影片可以有來源 FPS、母路徑及 runtime Proxy；圖片及固定畫面仍參與相同視覺計畫。

### Project snapshot

`.subtool` 只保存可重建資料，包含離線素材。DOM、AudioNode、Blob URL、frame、process、native handle 與進度由 runtime 持有。

`projectCanvas` 影響 History、dirty 與交付預設。`null` 使用素材尺寸，ASS PlayRes 固定 1920 × 1080。原生播放器依來源與畫布世代核對設定及呈現，比例不同才補邊。含 ASS 及邊框的截圖須取凍結畫布的合成結果。

檔首 `SUB Tool`／`User Name` 是實際寫檔環境，與 schema `version` 分開。桌面 `createProjectWorkspace()` 寫入當下版本與主機名稱，網頁記建置版及主機名不可得。這兩欄不參與 History／dirty。

## 4. 關鍵資料流

### 媒體載入

選檔與拖放共用 `media-loader.js`。先捕獲工作區及匯入意圖，再授權、探測、路由至原生或 HTML。直接可播來源可先註冊，需轉碼者待 metadata 就緒。來源波形、Proxy、聲道各自回報完成與失敗。[背景工作與交接](#proxy聲道與取消)

### Seek 與逐格

時間軸目標吸附格網，經序列映射，交可見 presenter 提供完成證據。UI 可以先到目標，`presentedTime()`、擷取及音訊 resume 等待實際畫格。播放頭追蹤先回讀實際捲動位置並同步 `State.viewStart`，只有可見範圍變動才重畫整條時間軸。[呈現生命週期](FPS_時碼一致性.md#3-呈現生命週期)

一般播放採用當次啟動的 `State.monitorPlaybackRate`。JKL 穿梭暫時接管倍率，結束後還原手選值。`Media` 將當前播放倍率乘上片段速度，並在 HTML 來源的 metadata 就緒或 mpv 完成換檔後重套。速度選單直接讀取手選值，專案與匯出則讀片段速度。

### 時間軸手勢

按下時捕獲主鍵 pointer、工作區、軌或物件及選取，超過門檻才預覽，放開一次提交。Esc、失焦、pointercancel 或換工作區撤回本次預覽。尺規 scrub／框選也受原工作區與軌資格限制。`beginGeometryEdit()` 管欄位與投影，DOM 處理座標與 clamp。軌道重排成功才更新順序及字幕索引。

### 字幕樣式

`effStyle()` 合成後送三路。單句只提交相對開窗狀態的實際變更，保留未改欄位的繼承；搬軌先保留原有效外觀，鎖定拒絕整組搬移。

`formats.js` 產生標準 ASS Dialogue 與可選自產 metadata。`buildSubtitleImportPlan()` 驗 metadata 的秒數、原格率及 frame 一致性；同格率還原定時字幕整數格，未定時原稿保留原值。合併軌道用逐句覆蓋保留原外觀。外來或無效資料回退標準 Dialogue；明確要求含 metadata 的匯出超過安全預算則整批失敗，保留視窗供重試。[ADR-0002](adr/0002-自產-ass-無損往返.md)

### 語音辨識與文本匹配

| 時機 | 規格與所有權 |
|---|---|
| 開窗／開始 | 開窗綁定原來源，開始才取最新 metadata 與聲道，凍結素材範圍、來源 URL、原稿、供應商與 FPS／DF。金鑰／導引保留於本次草稿。已接受工作透過 `Media.retainObjectURLs()` 保留自有 URL，最後持有者離開才撤銷 |
| 讀取／辨識 | 桌面先取得母檔音流，再按所選聲道用 FFmpeg 讀取最多 600 秒的 16 kHz mono。引擎保留重疊 PCM，邊讀邊找切點，對全零跳過推論。網頁 PCM WAV 可切片讀取，其他格式沿用 AudioBuffer，降採樣使用帶限濾波。分段快取綁定實際 PCM 及模型、詞表、時碼策略與聲道設定 |
| 語音字幕文字 | `transcribeAudioStream()` 在分段合併與去重後才整理中文字形與間距。語言來自明選、辨識服務回報或保守的文字判斷。中文聽寫用 OpenCC 的 `cn → t` 保留辨識用詞，文本匹配可另正規化比對用的語音副本 |
| 匹配／提交 | 每段以來源區間起點為零，回映時加一次偏移。逐行文本在可取消的 Worker 匹配。原稿行界、文字與順序照存。背景剪接有變動時先暫存候選，提交後字幕可附辨識原文、來源時間、詞時間及限同一回應的說話者標籤 |
| 取消／重入 | `speech-recognition-session.js` 每次通知、adapter 呼叫與提交前核對工作，避免同步訂閱者啟動的新工作被舊通知覆蓋。關窗保留工作，換專案取消；成功、失敗或取消都只釋放本工作的資源。公開進度遮蔽憑證、路徑及原稿 |

### 畫面文字辨識

播放點單格 OCR 凍結叫出工具時的專案時間。擷取前等待目前 presenter 證實畫格已呈現，框選、重試與校對都使用同一張影像。renderer 以畫格像素記錄選區的聯集與差集，將裁切、遮罩後的 PNG 交給 Electron 的本機 worker。確認後由 `commitPlayheadOcrCue()` 沿用或建立 OCR 軌，將校對文字從凍結格起寫入兩秒，吸附專案格網並建立一次 Undo。[影格格網](FPS_時碼一致性.md#i3-影格格網只有-snaptimetoframe)

`screen-text-recognition.js` 先按時間軸切點選出最上層可見影片，略過空隙，凍結母素材路徑、來源 In／Out、offset、速度、反轉及專案格網。`screen-text-session.js` 持有工作與部分結果；背景執行、換專案及加入字幕前都核對所有權。

main 核對 sender 及來源讀取權，`screen-text-runtime.js` 透過 NDJSON 啟動 `electron/card-vision/`。本機預覽用正式規劃器取得同一視軌、顯示方向、像素比例及裁切後的 JPEG，並查詢快取。初掃維持固定取樣格網，五分區追蹤可補選兩個基礎取樣之間的單一變化格。請求上限涵蓋初掃、複檢、校字及重送。忠實模式保留長角標和少數對白，綜藝模式可進一步精簡及校字。快取綁定來源、模型、區域與策略。

結果帶來源秒數與 `card`／`dialogue` 分類。renderer 依原 placement 回映，再按凍結格網建立「畫面字卡」／「畫面對白」軌，以一次 History 提交。不同區域的字幕可重疊。取消僅保留從來源起點連續完成的 prefix，不越過尚未完成視窗，並由使用者決定是否加入。部分結果可能尚未完成複檢或校字；模型判讀與邊界估計均須以實際畫格驗收，不承諾固定的影格精度。

憑證、原生執行與封裝邊界見 [Electron 維護手冊](Electron_維護手冊.md#主頁面媒體音訊與交付)，操作及 SRT 匯出見[使用說明](使用說明.md#辨識畫面文字)。

### 匯出

renderer 在送出時同步凍結已提交專案，依快照生成各列的字幕與規格。main 核准輸入輸出、編譯 argv、執行獨立程序並驗證成品，再由 watchdog 宣告終態。快照、重試與原始淡化時鐘見[交付計畫與成品階段](#交付計畫與成品階段)。

## 5. events.js（同步事件匯流排）

事件是同步、進程內且沒有 replay 的通知。新增 emit 前確認訂閱者，不為同一件事增加別名；State 變更及 render 通知應在同一交易邊界完成。

| 事件 | 發送者與消費責任 |
|---|---|
| `render:*`、`timeline:invalidate` | 模型通知 view 重新計算字幕、樣式、metadata 或幾何 |
| `action` | UI／快捷鍵交由組裝層派送命令 |
| `media:*` | 播放點、素材、presenter 及來源狀態 |
| `audio:busChanged` | Mixer 通知 Media 重套 gain 及音軌／時間軸重繪 |
| `audio:sourceRegistered` | State 提供同次註冊；配線 session 合併草稿／基準，History 僅在首次復原補入自動配置，Media 排程音訊效果核對聲道佈局並視需要重建 |
| `media:projectClipRestored` | Media 交接已物件化 record，History 補原始 metadata 並保留期間編輯 |
| `media:intakeJobs` | 背景工作狀態送專責進度 view，不接管交付生命週期 |
| `presets:changed` | `substyle.js` 發布接受／回復的樣式快照，由 `preset-library.js` 單一訂閱者刷新目前樣式 view |

## 6. 桌面版與網頁版

| 能力 | 網頁版 | Electron |
|---|---|---|
| 預覽 | HTML video／WebCodecs | HTML／mpv／WebCodecs |
| 非原生與大檔 | 受瀏覽器解碼、記憶體及格式限制 | 母路徑、ffprobe／ffmpeg、串流及 Proxy |
| 多聲道 | 依瀏覽器／解碼能力 | 來源 metadata 與逐聲道快取 |
| 播放點單格 OCR | 不支援 | 本機 PaddleOCR／Tesseract，可離線框選與校對 |
| 影片範圍畫面文字辨識 | 不支援 | Rust 本機預覽及追蹤。新增雲端請求需供應商金鑰，請求上限設為 0 可僅讀快取 |
| 檔案存取 | File API／下載 | preload 與 main capability |
| 交付 | 瀏覽器可下載的輸出 | 持久背景 ffmpeg 佇列 |

Renderer 拿到路徑字串不代表有讀寫能力，授權須由 main 裁定。差異在 adapters 處理，共用的字幕、時間軸、樣式與音訊規則維持同一份。

## 7. WebCodecs 與 demux

| 模組（`src/decode/`） | 診斷要點 |
|---|---|
| `demux.js`、`sample-index.js` | MP4 edit list、sample 位址、PTS、keyframe。樣本解碼與檔案位址順序可不同，視窗依最小 offset 到最大 offset＋size，逐樣本驗完整 bytes |
| `source-frame-index.js` | HTML／mpv／WebCodecs 共用有界索引，合併探測。短回應／部分證據可重試，逐格查詢至少隔一秒。依快取項目資格更新，保留較完整成功結果 |
| `response-reader.js` | Range 及整檔退路逐段驗實收 bytes，超限立即取消並釋鎖。Content-Length 僅提前拒絕。整檔退路 1,500 MiB，瀏覽器人聲母素材 100 MB；伺服器忽略 Range 時仍設限 |
| `player.js` | 每個作用層獨立 decoder／reader，各有最多四個 LRU 位元組視窗。同一來源只共用不可變索引與整檔退路 payload。最後使用者離開才取消共用解析 |

`visualStackPlan()` 決定層序。圖片全在上方可走 DOM／guide，夾在影片間或下方時由 Canvas 畫完整 stack。每層影片以 timestamp／區間涵蓋各自來源目標，圖片已解碼並繪製，才發布 `Media.previewComposition()`。Canvas 已合成的圖片保留 wrapper／控制點，避免疊畫 bitmap。

等待 bytes／bitmap 或單次繪製失敗可保留上一張完整畫面；當前來源／圖片真的失敗則交回原 presenter。圖片依工作集 tick 退避 1、2、4 秒至最多 30 秒；將來預取失敗不撤下仍有效的畫格。新 stack 完整後才能再接管。

decoder、讀取或設定失敗清理自己的 frame／reader。`disposeAll()` 在序列卸載或停用時涵蓋圖片回呼、私有畫布、解碼資源與 demux 引用，即使影片層已先淘汰。遲到 frame 一律關閉。

### 擷取同一張畫面

`capturePreviewFrame()` 依 `mpvPresenting()` 與真正可見的 Canvas／HTML 選擇。凍結畫布、composition 時間、圖片、FPS／DF：舊完整畫面只配同時點疊層。HTML 用 `withPresentedFrame()` 取得目標畫格才複製，`previewFadeDarkness()` 只淡化影片。純音訊／圖片走黑底，不等待影片。三路共用 `imageLayerPlan()`、`fadeAlphaAtTimeline()` 與軌道裁切。[原生擷取與畫格 hold](Electron_維護手冊.md)

## 8. 字幕渲染細節

文字只在明確換行處分行，列表與檢查面板依 runtime 換行計數。底框以全段文字外框向外擴張。驗收九宮格對齊、直書、背景、框線、陰影、角度、字距、行距，逐項比較三路。

`subtitle-preview-index.js` 以專案整數畫格建立字幕區間索引，供預覽疊層與列表播放標記共用。編輯、匯入或 Undo 後重建索引。原生播放器在來源格率不同時的定位方式見 [FPS／時碼](FPS_時碼一致性.md#ui-權威與實際呈現)。

`subtitle-search.js` 的列表、標示、取代共用字面搜尋與大小寫規則，使用者輸入先跳脫，非全域查詢避免跨 cue 污染 `lastIndex`。

## 9. shared/

`shared/*.cjs` 僅容納 renderer／main 共用的零相依純規則。CSS／ASS 各自實作同一樣式規格，檔名淨化與路徑圍堵各守不同邊界。加入前讀[共用規則與分層條件](../shared/README.md)。

## 10. 驗證策略

| 層級 | 要證明的內容 |
|---|---|
| 純規則 | 數值、格網、狀態機、合法範圍與極端資料 |
| 介面回歸 | 正式 caller 的提交、取消、競爭及 Undo／Redo |
| 共享契約 | renderer／main 同一規則及 CSS／ASS 三路表示 |
| Repository | 來源 HTML、目錄、命名、連結及安裝包內容 |
| Renderer 真機 | 真實 DOM、computed style、鍵盤／滑鼠與對話框 |
| Native／媒體 | 實際畫格、PCM、聲音數、ffprobe 成品及程序釋放 |

新增測試要跨過真實 caller 使用的同一介面。對非同步修復先得到可重現紅訊號，再證明舊結果失效、資源釋放及新工作可繼續。播放既看目標，也看實際 presenter；音訊既看節點數，也看 PCM 位置與內容。

lint、完整測試、build、CDP、大檔與安裝驗收的命令及順序集中於[開發與驗證](開發與驗證.md)。文件中的成功紀錄不代替新變更的驗證，文件版號及歷史則以 manifest 與[版本變更紀錄](版本變更紀錄.md)各自負責。
